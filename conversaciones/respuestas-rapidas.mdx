Si atiendes clientes por mensaje, hay entre diez y quince respuestas que escribes una y otra vez: el horario, la dirección, los precios, cómo llegar, qué documentos traer. Las respuestas rápidas las guardan para que las insertes escribiendo dos letras.

No es solo velocidad. Es **consistencia**: todo tu equipo responde lo mismo, bien escrito, sin inventar cada vez.

## Crea una respuesta rápida

<Steps>
  <Step title="Abre el gestor">
    Ve a **Configuración → Respuestas rápidas** y pulsa **Crear**.
  </Step>
  <Step title="Define el atajo">
    Usa un prefijo consistente para que aparezcan agrupadas:

    ```text
    /horario
    /direccion
    /precios
    /comollegar
    /formasdepago
    ```
  </Step>
  <Step title="Escribe el mensaje">
    Puedes incluir variables para que se personalice solo:

    ```text
    Hola {{contact.first_name}}, nuestro horario es de lunes a viernes
    de 9:00am a 6:00pm y sábados de 9:00am a 1:00pm.
    ¿Te gustaría que te agende una cita?
    ```
  </Step>
  <Step title="Guarda">
    Queda disponible de inmediato para todo el equipo.
  </Step>
</Steps>

## Úsala

En el cuadro de respuesta, escribe `/` seguido del atajo. Aparece una lista con las coincidencias, seleccionas y el texto se inserta.

<Tip>
  El texto se inserta como texto normal, así que puedes editarlo antes de enviar. Úsalas como punto de partida, no como respuesta rígida: agregar una línea personalizada cambia por completo cómo se siente el mensaje.
</Tip>

## Las quince que todo negocio necesita

| Atajo | Contenido |
| --- | --- |
| `/saludo` | Bienvenida y pregunta de apertura |
| `/horario` | Días y horas de atención |
| `/direccion` | Dirección con referencia de cómo llegar |
| `/ubicacion` | Enlace al mapa |
| `/precios` | Rango de precios o enlace a la lista |
| `/formasdepago` | Métodos que aceptas |
| `/agendar` | Enlace de reserva |
| `/confirmacion` | Confirmación de cita con fecha y hora |
| `/reprogramar` | Cómo cambiar una cita |
| `/politicacancelacion` | Reglas de cancelación |
| `/quetraer` | Qué debe llevar el cliente |
| `/tiempoentrega` | Plazos de entrega o duración del servicio |
| `/garantia` | Condiciones de garantía |
| `/fueradehorario` | Respuesta cuando escriben de madrugada |
| `/despedida` | Cierre con invitación a volver |

## Diferencia con las plantillas de WhatsApp

<CardGroup cols={2}>
  <Card title="Respuestas rápidas" icon="bolt">
    Atajos internos tuyos. No requieren aprobación de nadie. Solo funcionan **dentro** de la ventana de 24 horas de WhatsApp, porque son mensajes libres.
  </Card>

  <Card title="Plantillas de WhatsApp" icon="whatsapp">
    Deben ser aprobadas por Meta. Son las únicas que puedes enviar **fuera** de la ventana de 24 horas.
  </Card>
</CardGroup>

<Warning>
  Si intentas usar una respuesta rápida con alguien que no te escribe hace más de 24 horas, el mensaje no sale. Necesitas una plantilla aprobada. Ver [Plantillas de WhatsApp](/whatsapp/plantillas).
</Warning>
