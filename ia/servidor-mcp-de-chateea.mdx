El servidor MCP de Chateea permite que asistentes y agentes de IA externos (como Cursor, Windsurf, OpenAI Playground, clientes compatibles con Claude, n8n o tus propias aplicaciones) se conecten de forma segura a tu cuenta. Una vez conectados, pueden buscar contactos, actualizar datos, enviar mensajes, consultar oportunidades y calendarios, o crear publicaciones y blogs a partir de instrucciones en lenguaje natural.

MCP (Model Context Protocol) es un protocolo estándar que funciona como puente entre un cliente de IA y un servicio: el cliente descubre qué herramientas tiene disponibles, consulta datos y ejecuta las acciones que le hayas autorizado. No necesitas instalar ningún SDK: la conexión es por HTTP.

## Para qué te sirve

- **Un solo punto de acceso:** conectas tu IA a contactos, conversaciones, calendarios, oportunidades, pagos, blogs, correos y redes sociales desde un único servidor.
- **Acceso controlado:** usas un token de integración privada con los permisos (scopes) que tú eliges.
- **Automatización en lenguaje natural:** tu asistente ejecuta tareas a partir de instrucciones sencillas.
- **Compatible con muchas herramientas:** cualquier cliente que admita servidores MCP por HTTP y permita enviar cabeceras de autenticación.

## Antes de empezar

Necesitas:

- Acceso a tu cuenta de Chateea con permisos para crear integraciones privadas.
- Un **token de integración privada** con los permisos necesarios.
- El **ID de tu cuenta**, que encuentras en **Configuración → Perfil del negocio**.
- La **URL del servidor MCP de Chateea**. Solicítala a soporte en **help@chateea.com**.
- Un cliente compatible con MCP.

## Configurar la conexión

<Steps>
  <Step title="Crea un token de integración privada">
    Ve a **Configuración → Integraciones privadas** y haz clic en **Crear nueva integración**. Elige los permisos que necesita tu flujo (consulta la tabla de permisos recomendados), haz clic en **Crear integración** y copia el token generado. Guárdalo en un lugar seguro.
  </Step>
  <Step title="Agrega el servidor a tu cliente MCP">
    En la configuración de servidores MCP de tu cliente, añade la URL del servidor y las cabeceras de autenticación:

    ```json
    {
      "mcpServers": {
        "chateea": {
          "url": "<URL-del-servidor-MCP-de-Chateea>",
          "headers": {
            "Authorization": "Bearer <tu-token>",
            "locationId": "<id-de-tu-cuenta>"
          }
        }
      }
    }
    ```

    Sustituye `<tu-token>` por tu token de integración privada y `<id-de-tu-cuenta>` por el ID de tu cuenta.
  </Step>
  <Step title="Elige las herramientas">
    Cuando el cliente se conecte, verás las herramientas disponibles según los permisos del token. Activa solo las que tu agente necesita.
  </Step>
</Steps>

## Permisos recomendados

Concede únicamente los permisos que tu caso de uso requiera.

| Área | Permisos |
| --- | --- |
| **Contactos** | Ver contactos, Editar contactos |
| **Conversaciones** | Ver conversaciones, Editar conversaciones |
| **Mensajes** | Ver mensajes de conversación, Editar mensajes de conversación |
| **Oportunidades** | Ver oportunidades, Editar oportunidades |
| **Calendarios** | Ver calendarios, Editar calendarios |
| **Eventos de calendario** | Ver eventos, Editar eventos |
| **Pagos** | Ver órdenes de pago, Ver transacciones |
| **Otros** | Ver campos personalizados, Ver formularios, Ver datos de la cuenta |

### Ejemplo de llamada

```python
import requests

headers = {
    "Authorization": "Bearer TU_TOKEN",
    "locationId": "ID_DE_TU_CUENTA"
}

data = {
    "tool": "contacts_get-contact",
    "input": {"contactId": "abc123"}
}

response = requests.post("URL_DEL_SERVIDOR_MCP", headers=headers, json=data)
print(response.json())
```

## Qué puedes pedirle a tu IA

Con el servidor conectado, tu asistente usa las herramientas en segundo plano. Por ejemplo:

- "¿Tengo un contacto que se llame Ana Torres?" (busca con las herramientas de contactos).
- "Muéstrame las oportunidades abiertas de mi cuenta." (consulta y resume las oportunidades).
- Crear o actualizar un contacto, agregar o quitar etiquetas.
- Buscar en el historial de conversaciones y enviar un mensaje a un contacto.
- Revisar los eventos del calendario o los datos de una orden de pago.

## Usarlo con n8n

El servidor MCP de Chateea funciona con n8n sin plugins personalizados. Así puedes conectar los datos de tu cuenta con tus flujos de n8n y automatizar procesos entre ambas plataformas, incluso con flujos de n8n que ya tengas.

<Steps>
  <Step title="Configura la conexión MCP">
    En el agente o cliente MCP de n8n, añade la URL del servidor MCP de Chateea y las cabeceras de autenticación (el token y, si quieres limitar las solicitudes a una cuenta, el `locationId`), con el mismo formato del ejemplo anterior.
  </Step>
  <Step title="Arma tu flujo en n8n">
    Configura los pasos de tu flujo de n8n que usarán las herramientas de Chateea.
  </Step>
  <Step title="Prueba">
    Ejecuta el flujo de prueba y confirma que los datos se mueven correctamente entre ambas plataformas.
  </Step>
</Steps>

## Seguridad

Cada solicitud debe incluir un token de integración privada válido, el ID de tu cuenta y los permisos necesarios para la herramienta que se usa. Todo viaja cifrado por HTTPS.

<Warning>
  Trata tu token como una contraseña. Nunca lo publiques en repositorios públicos, capturas de pantalla, indicaciones compartidas ni en código que se ejecute en el navegador.
</Warning>

## Buenas prácticas

- **Mínimo privilegio:** activa solo los permisos que el flujo necesita.
- **Cuidado con la escritura:** concede permisos de edición solo si el agente debe crear o actualizar datos.
- **Prueba antes de usarlo en serio:** confirma que el cliente llama a las herramientas correctas y devuelve lo esperado.
- **Supervisa la actividad:** revisa lo que hace la IA cuando tiene permisos de escritura.
- **Renueva los tokens:** cámbialos periódicamente o cuando quieras revocar un acceso.
- **Instrucciones claras:** indica a tu agente cuándo debe leer datos, cuándo actualizar y cuándo pedir confirmación.
