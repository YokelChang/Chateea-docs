Ask AI puede crear una base de conocimiento por ti en una conversación guiada: elige la fuente de contenido, crea la base y la conecta a tu IA conversacional o a tu agente de IA de voz. Es la forma más rápida de darle a tus agentes la información de tu negocio para que respondan con precisión, sin perder el control sobre las fuentes y la configuración.

## Para qué te sirve

- **Varias fuentes posibles:** tu voz de marca, el sitio web de tu perfil del negocio o contenido que agregues a mano.
- **Todo en un solo flujo:** crea la base y conéctala a la IA conversacional o a la IA de voz sin cambiar de pantalla.
- **Configuración guiada:** un proceso ordenado que reduce errores.
- **Rastreo web controlado:** Ask AI te pide aprobación antes de rastrear un sitio web.
- **Base vacía si la necesitas:** puedes crearla sin contenido y añadir las fuentes después.

El proceso siempre sigue el mismo orden:

1. Definir la fuente de contenido.
2. Crear la base de conocimiento.
3. Rastrear el sitio web (si aplica).
4. Configurar las preguntas frecuentes.
5. Conectar la base a un agente de IA.

## Antes de empezar

- Asegúrate de tener acceso a Ask AI y a la configuración de bases de conocimiento.
- Si vas a conectar la base a un agente, necesitas permisos para gestionar la IA conversacional o la IA de voz.
- Revisa tu **voz de marca** si quieres que Ask AI use esa información.
- Comprueba que el sitio web de **Configuración → Perfil del negocio** sea correcto si quieres rastrearlo.
- Ten en cuenta que Ask AI te pedirá aprobación antes de rastrear el sitio.

<Info>
  La IA conversacional puede usar **varias** bases de conocimiento. Cada agente de IA de voz admite **una sola** base de conocimiento.
</Info>

## Cómo elige Ask AI la fuente de contenido

### Voz de marca

Tu voz de marca ya contiene datos de tu negocio, tu tono, tus servicios y otra información de contexto. Ask AI puede sugerirla cuando tiene información suficiente. Es buena opción cuando:

- Tu perfil de negocio ya está bien definido.
- Quieres que las respuestas de la IA mantengan tu tono y tu posicionamiento.
- Necesitas un punto de partida rápido para preguntas frecuentes o información general.

### Sitio web del perfil del negocio

Ask AI puede usar como fuente principal el sitio web que tienes en tu perfil del negocio. Antes de rastrearlo te pide aprobación y te deja:

- Rastrear el sitio sugerido.
- Indicar otra URL.
- Omitir el rastreo y configurar las fuentes a mano.

Así puedes crear una base de conocimiento con el contenido de tu web aunque no tengas voz de marca configurada.

### Configuración manual

Si no hay voz de marca ni sitio web, Ask AI crea una base vacía y te orienta para añadir fuentes después, como documentos, texto enriquecido, preguntas frecuentes, rastreos web y tablas.

## Cómo se conecta la base a tus agentes

### IA conversacional

Ask AI puede conectar la base a un bot de IA conversacional existente o a uno nuevo. Como la IA conversacional admite varias bases de conocimiento, puedes combinar el contenido de tu web, tus preguntas frecuentes, tus políticas y otros recursos en un mismo bot.

### IA de voz

Ask AI también puede conectar la base a un agente de IA de voz. Como cada agente de voz admite una sola base, al conectarla pasa a ser su base activa. Después puedes seguir ajustando las indicaciones, los objetivos y el comportamiento desde la configuración del agente de voz.

## Cómo crear una base de conocimiento con Ask AI

<Steps>
  <Step title="Abre Ask AI">
    Abre **Ask AI** desde el menú de navegación e inicia una conversación nueva.
  </Step>
  <Step title="Pide la base de conocimiento">
    Describe lo que quieres. Por ejemplo: "Crea una base de conocimiento con mi sitio web y conéctala a la IA conversacional" o "Crea una base de conocimiento con mi voz de marca y conéctala a mi agente de voz". Ask AI reconoce la solicitud e inicia el proceso.
  </Step>
  <Step title="Confirma la fuente">
    Según tu configuración, Ask AI propondrá usar la voz de marca, tu sitio web o la configuración manual. Si detecta un sitio web, confirma si debe rastrearlo o si prefieres otra URL.
  </Step>
  <Step title="Revisa la creación">
    Ask AI crea la base y configura la fuente. Si usas un sitio web, se añade una fuente de rastreo web, el rastreo empieza automáticamente y el contenido estará disponible para búsquedas cuando termine el procesamiento.
  </Step>
  <Step title="Configura las preguntas frecuentes">
    Si tienes voz de marca, Ask AI puede proponerte preguntas frecuentes basadas en tu negocio. Si solo usaste tu web, puedes añadirlas más tarde desde la configuración de la base de conocimiento.
  </Step>
  <Step title="Conecta la base a un agente">
    Elige si quieres conectarla a un bot de IA conversacional existente, a uno nuevo o a un agente de IA de voz existente. Una vez conectada, el agente empieza a usarla en sus conversaciones.
  </Step>
</Steps>

<Warning>
  Revisa siempre la base de conocimiento después de crearla: comprueba el contenido de las fuentes, las preguntas frecuentes generadas, los resultados del rastreo y a qué agente quedó conectada.
</Warning>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Puedo crear una base de conocimiento sin voz de marca?">
    Sí. Ask AI puede usar el sitio web de tu perfil del negocio como fuente.
  </Accordion>
  <Accordion title="¿Ask AI rastrea sitios web automáticamente?">
    No. Siempre te pide aprobación antes de rastrear un sitio.
  </Accordion>
  <Accordion title="¿Puedo usar otro sitio web distinto al de mi perfil?">
    Sí. Durante la configuración puedes indicar otra URL antes de que empiece el rastreo.
  </Accordion>
  <Accordion title="¿La IA conversacional puede usar varias bases de conocimiento?">
    Sí. Un bot de IA conversacional puede tener varias bases conectadas.
  </Accordion>
  <Accordion title="¿Cómo funciona con la IA de voz?">
    Cada agente de voz admite una sola base de conocimiento. La que conectes pasa a ser la fuente activa de ese agente.
  </Accordion>
  <Accordion title="¿Puedo añadir preguntas frecuentes después?">
    Sí. Puedes crearlas o editarlas cuando quieras desde la configuración de la base de conocimiento.
  </Accordion>
  <Accordion title="¿Qué pasa si no tengo sitio web configurado?">
    Ask AI crea una base vacía y te guía para añadir las fuentes manualmente.
  </Accordion>
</AccordionGroup>
