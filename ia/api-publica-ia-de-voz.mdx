La API pública de la IA de voz te permite gestionar tus agentes desde tus propios sistemas: crear y actualizar agentes y acciones, consultar el catálogo de voces y obtener registros y transcripciones de llamadas. Es útil si tienes un equipo técnico o un desarrollador que quiere integrar la IA de voz con tus aplicaciones, informes o procesos internos.

<Note>
  Para obtener las credenciales de acceso, la URL base y la documentación técnica de la API de Chateea, escribe a soporte de Chateea en **help@chateea.com**.
</Note>

## Para qué te sirve

- **Acceso a los datos:** obtén resultados, transcripciones y métricas de llamadas para tus propios informes o análisis.
- **Integración con tus procesos:** automatiza la configuración y adapta la IA de voz a tus aplicaciones.
- **Configuración consistente:** crea y actualiza agentes con la misma configuración sin hacerlo a mano uno por uno.
- **Webhooks en tiempo real:** recibe resultados, transcripciones y resúmenes de las llamadas en tus sistemas.

## Qué puedes hacer con la API

### Voces (catálogo)

| Operación | Qué hace |
| --- | --- |
| **Listar voces** | Devuelve una lista paginada de voces. Puedes filtrar por idioma y enviar un `agentId` para ver solo las voces compatibles con ese agente. |
| **Detalle de una voz** | Devuelve la información de una voz, incluida una URL de muestra para escucharla. |

### Registros de llamadas

| Operación | Qué hace |
| --- | --- |
| **Listar registros** | Devuelve los registros de llamadas de los agentes de tu cuenta. Permite filtrar por agente, contacto, tipo de llamada, tipo de acción y rango de fechas (interpretado en la zona horaria IANA que indiques). Admite ordenamiento y paginación que empieza en 1. |
| **Obtener un registro** | Devuelve una llamada concreta a partir de su ID, con la transcripción cuando está disponible. |

### Agentes

| Operación | Qué hace |
| --- | --- |
| **Crear agente** | Crea un agente nuevo con su configuración. |
| **Actualizar agente** | Modifica parcialmente un agente existente. |
| **Listar agentes** | Devuelve la lista paginada de agentes de tu cuenta. |
| **Obtener agente** | Devuelve la configuración completa de un agente. |
| **Eliminar agente** | Elimina un agente y toda su configuración. |

### Acciones

Las acciones definen lo que puede hacer un agente durante una llamada, como llamar a un webhook, consultar datos o enviar resultados.

| Operación | Qué hace |
| --- | --- |
| **Crear acción** | Agrega una acción nueva a un agente. |
| **Actualizar acción** | Modifica el comportamiento y la configuración de una acción. |
| **Obtener acción** | Devuelve la configuración de una acción, incluidos sus parámetros. |
| **Eliminar acción** | Elimina una acción de forma permanente. |

<Warning>
  Eliminar un agente o una acción por API es permanente. Prueba tus integraciones primero con agentes de prueba.
</Warning>

  </Accordion>

  </Accordion>
