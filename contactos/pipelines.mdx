Un pipeline es la representación visual de tu proceso de ventas o de servicio. Cada pipeline se divide en etapas, y cada oportunidad avanza de izquierda a derecha a medida que progresa. Así tu equipo ve de un vistazo en qué punto está cada negocio, qué acción toca y dónde se están quedando atascadas las ventas.

Encuentras tus pipelines en **Oportunidades → Pipelines**. La lista muestra todos los pipelines de tu cuenta, cuántas etapas tiene cada uno y cuándo se modificaron por última vez.

## Para qué te sirve un pipeline

- **Visibilidad:** sabes al instante dónde está cada oportunidad.
- **Consistencia:** todo el equipo sigue el mismo proceso para mover prospectos y clientes.
- **Eficiencia:** puedes automatizar seguimientos, recordatorios y asignación de tareas cuando una oportunidad cambia de etapa.
- **Seguimiento del rendimiento:** mides tasas de conversión, detectas cuellos de botella y revisas la salud general de tus ventas.

## Etapas del pipeline

Cada etapa representa un paso concreto del recorrido de tu cliente. Define etapas claras y orientadas a la acción, de modo que cualquier persona del equipo sepa exactamente cuándo una oportunidad debe pasar a la siguiente.

Desde la pantalla de edición de un pipeline puedes:

- Cambiar el nombre de las etapas.
- Reordenarlas.
- Controlar si cada etapa aparece en los informes.
- Añadir etapas nuevas o eliminar las que ya no uses.

### Eliminar una etapa sin perder oportunidades

Al borrar una etapa, Chateea te pide elegir otra etapa de destino para mover todas las oportunidades que contenía. Así no pierdes ningún registro.

<Steps>
  <Step title="Abre el pipeline">
    Ve a **Oportunidades → Pipelines** y abre el pipeline que quieres editar.
  </Step>
  <Step title="Elimina la etapa">
    Haz clic en el ícono de eliminar junto a la etapa.
  </Step>
  <Step title="Elige la etapa de destino">
    Selecciona la etapa a la que se moverán las oportunidades existentes.
  </Step>
  <Step title="Confirma">
    Confirma la eliminación. Todas las oportunidades de la etapa borrada pasan automáticamente a la etapa elegida.
  </Step>
</Steps>

## Ejemplos de etapas

### Pipeline de ventas

| Etapa | Qué significa |
| --- | --- |
| Captación | Nuevas consultas desde formularios, llamadas o chats |
| Calificación | Se confirma presupuesto, necesidad y encaje |
| Cita agendada | Llamada de descubrimiento o demostración reservada |
| Propuesta o negociación | Se envía y se discute la oferta |
| Cierre | La oportunidad se marca como ganada o perdida |

### Pipeline de un negocio de servicios

Nueva consulta → Llamada de descubrimiento agendada → Servicio o paquete elegido → Pago recibido → Incorporación del cliente.

<Tip>
Define una regla clara para cada avance. Por ejemplo: mueve una oportunidad a **Cita agendada** solo cuando la reunión esté confirmada en el calendario.
</Tip>

### Otros ejemplos por sector

- **Inmobiliaria:** Nuevo prospecto → Visita a la propiedad → Oferta → Contrato firmado → Cerrado.
- **Coaching:** Consulta → Llamada de descubrimiento → Programa elegido → Pago → Incorporación.
- **Servicios profesionales:** Prospecto → Llamada de estrategia → Propuesta → Acuerdo → Cliente activo.

Adapta estos modelos a tu negocio. Lo importante es que las etapas reflejen cómo vendes de verdad.

## Buenas prácticas

- **Mantenlo simple.** Usa solo las etapas que de verdad importan. Demasiadas etapas frenan al equipo y restan claridad.
- **Automatiza con criterio.** Crea flujos de trabajo que envíen un seguimiento cuando una oportunidad lleva demasiado tiempo en una etapa, o que asignen tareas cuando llega a una etapa clave.
- **Revisa con frecuencia.** Cada semana o cada mes, limpia oportunidades obsoletas, ajusta las definiciones de las etapas y revisa las tasas de conversión.
- **Decide con datos.** Usa los informes de oportunidades para responder preguntas como: ¿en qué etapa se pierden más oportunidades?, ¿qué etapa tarda más en completarse?, ¿cuál es la tasa de cierre de cada etapa?

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Pierdo oportunidades si elimino una etapa?">
    No. Al eliminar una etapa eliges otra a la que se moverán todas sus oportunidades.
  </Accordion>
  <Accordion title="¿Mis automatizaciones siguen funcionando si edito el pipeline?">
    Sí. Los flujos de trabajo y disparadores basados en pipelines siguen funcionando con normalidad. Si eliminas una etapa que usa un flujo de trabajo, revisa ese flujo para apuntar a la nueva etapa.
  </Accordion>
  <Accordion title="Veo la página de pipelines con un diseño distinto. ¿Cambió algo?">
    La página de pipelines puede mostrarse con un diseño renovado. Las funciones son las mismas: el cambio mejora la interfaz y hace más segura la gestión de etapas.
  </Accordion>
</AccordionGroup>
