Cada red social pone sus propias reglas sobre el tipo de archivo, el tamaño, la duración de los videos y la cantidad de texto que acepta. Si una publicación no cumple esas reglas, la red la rechaza y el post aparece como fallido en el Planificador social. Usa esta página como referencia antes de preparar tu contenido.

<Tip>
Si trabajas con imágenes de uso general, estos dos tamaños funcionan bien en casi todas las redes: **horizontal** de 1.024 x 512 píxeles y **vertical** de 800 x 1.200 píxeles. Con el tiempo verás qué formato rinde mejor para tu marca.
</Tip>

<Warning>
Instagram cuenta los caracteres codificados para URL. Algunos emojis y caracteres especiales cuentan como varios caracteres, así que una descripción que en el editor parece estar dentro del límite puede ser rechazada.
</Warning>

## Límites de publicación por red

Las redes sociales limitan cuántas publicaciones puede enviar cada usuario activo en un período. Si los superas, las publicaciones siguientes fallarán hasta que el contador se reinicie.

| Red | Límite |
| --- | --- |
| Perfil de Empresa de Google | 100 publicaciones cada 24 horas |
| Facebook | 200 publicaciones por hora |
| Reels de Facebook | 30 publicaciones cada 24 horas |
| Instagram | 25 publicaciones cada 24 horas |
| LinkedIn | 200 publicaciones cada 24 horas |
| TikTok | 15 publicaciones cada 24 horas |
| YouTube | 25 publicaciones cada 24 horas |
| Pinterest | 25 publicaciones cada 5 minutos |

## Otras reglas por red

La **vista previa de enlace** es la tarjeta con imagen y título que se genera al pegar una URL (etiqueta OG). Algunas redes la muestran y otras no. Además, ciertos tipos de publicación exigen al menos un archivo multimedia.

| Red y tipo | Vista previa de enlace | Requiere al menos un archivo | Mezcla de imágenes y videos |
| --- | --- | --- | --- |
| Facebook: publicación | Sí | No | No |
| Facebook: reel | No | Sí | No |
| Facebook: historia | No | Sí | No |
| Instagram: publicación | No | Sí | Sí |
| Instagram: reel | No | Sí | No |
| Instagram: historia | Sí | No | No |
| YouTube: shorts y videos | No | Sí (el video) | No |
| LinkedIn: perfil y páginas | Sí | No | No |
| LinkedIn: carrusel en PDF | Sí | Sí | No |
| TikTok personal y empresa | No | Sí | No |
| Perfil de Empresa de Google | Sí | No | No |
| Pinterest | No | Sí | No |
| Comunidades | No | Sí | Sí |

## Consejos para evitar publicaciones fallidas

- Revisa el tipo de publicación (publicación, historia o reel) antes de subir el archivo: cada uno tiene límites distintos.
- Comprime los videos pesados antes de subirlos, sobre todo para Instagram.
- No mezcles imágenes y videos en redes que no lo permiten.
- Si programas muchas publicaciones a la vez, reparte los horarios para no chocar con los límites de publicación.
