El portal del cliente y su app móvil se pueden usar en varios idiomas. Tú defines un idioma predeterminado para todos tus clientes y cada cliente puede cambiarlo después desde su propia cuenta, tanto en la web como en el móvil.

Si atiendes clientes de distintos países, esto hace que cada uno navegue sus cursos, comunidades y facturas en el idioma que entiende mejor, y reduce las dudas y los mensajes de soporte.

## Cómo funciona

- **Idioma predeterminado:** lo defines tú para todo el portal. Se aplica en la página de inicio de sesión y en toda la experiencia web del portal.
- **Idioma de cada cliente:** cada cliente puede elegir el suyo, en la web o en la app móvil. Su elección reemplaza el predeterminado solo para él.
- **Inglés como respaldo:** si no hay idioma elegido ni por ti ni por el cliente, el portal se muestra en inglés.

El cambio se aplica al instante, y tanto tú como tus clientes pueden cambiarlo tantas veces como quieran.

## Definir el idioma predeterminado del portal

<Steps>
  <Step title="Abre la configuración del portal">
    Ve a **Membresías → Portal del cliente → Configuración → Configuración de idioma**.
  </Step>
  <Step title="Elige el idioma">
    Selecciona el idioma que verán todos tus clientes por defecto.
  </Step>
  <Step title="Guarda">
    Haz clic en **Guardar**. A partir de ese momento, la página de inicio de sesión y el portal web se muestran en ese idioma.
  </Step>
</Steps>

<Tip>
Si la mayoría de tus clientes habla español, deja el español como predeterminado. Los clientes que prefieran otro idioma lo pueden cambiar ellos mismos sin que tengas que hacer nada.
</Tip>

## Cómo cambia el idioma tu cliente en la web

Tu cliente entra al portal desde la dirección del portal (o tú puedes entrar desde **Membresías → Portal del cliente** para probarlo). Después:

<Steps>
  <Step title="Abre la cuenta">
    Hace clic en su logo o foto, arriba a la derecha, y elige **Administrar tu cuenta**.
  </Step>
  <Step title="Elige el idioma">
    En **Configuración de idioma**, selecciona su idioma en la lista desplegable.
  </Step>
</Steps>

## Cómo cambia el idioma tu cliente en la app móvil

<Steps>
  <Step title="Abre el perfil">
    Toca **Perfil** en la barra inferior.
  </Step>
  <Step title="Entra a la configuración">
    Toca **Configuración** y luego **Configuración de idioma**.
  </Step>
  <Step title="Elige y guarda">
    Selecciona el idioma de la lista y toca **Guardar**.
  </Step>
</Steps>

## Idiomas disponibles

Estos idiomas están disponibles en la web y en la app móvil:

| Idioma | Región |
| --- | --- |
| Español | ES |
| Alemán | DE |
| Francés (Canadá) | CA |
| Francés (Francia) | FR |
| Neerlandés | NL |
| Portugués (Portugal) | PT |
| Portugués (Brasil) | BR |
| Italiano | IT |
| Sueco | SE |
| Finés | FI |
| Noruego | NO |

El inglés es el idioma predeterminado cuando no se elige ningún otro.

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿El cambio de idioma se aplica de inmediato?">
    Sí. En cuanto se guarda, el nuevo idioma se aplica.
  </Accordion>
  <Accordion title="¿Se puede cambiar el idioma más de una vez?">
    Sí, en cualquier momento.
  </Accordion>
  <Accordion title="¿Qué pasa si alguna parte no está traducida?">
    Donde no haya traducción disponible, el portal muestra el texto en inglés.
  </Accordion>
  <Accordion title="¿Puedo fijar un idioma para todos los clientes nuevos?">
    Sí. Ve a **Membresías → Portal del cliente → Configuración → Configuración de idioma**, elige el idioma y guarda. Se aplica a la página de inicio de sesión y al portal web de todos tus clientes.
  </Accordion>
  <Accordion title="¿El idioma del portal cambia el idioma de mi cuenta de Chateea?">
    No. El idioma de tu panel de Chateea se configura aparte, en **Configuración → Perfil del negocio** o en **Mi perfil**. Ver [Cambiar el idioma de la plataforma](/configuracion/idioma-de-la-plataforma).
  </Accordion>
</AccordionGroup>
