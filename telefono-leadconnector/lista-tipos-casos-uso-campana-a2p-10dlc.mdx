## Descripción general

Las tablas a continuación muestran los tipos de casos de uso de campaña que estarán disponibles para su registro bajo el programa A2P 10DLC de Estados Unidos.

Tenga en cuenta que los límites máximos actuales de campañas por caso de uso son los siguientes:

  <Card title="100 marcas" icon="landmark">
    Para organizaciones sin fines de lucro y gubernamentales.
  </Card>

  <Card title="200 marcas" icon="building">
    Con fines de lucro, tanto privadas como públicas.
  </Card>
</CardGroup>

Para obtener información detallada sobre A2P 10DLC, fechas límite, requisitos de registro y más, consulte [¿Qué es A2P 10DLC?](https://help.leadconnectorhq.com/en/support/solutions/articles/155000000756)

Para obtener información detallada sobre las tarifas, consulte [¿Qué precios y tarifas están asociados al servicio A2P 10DLC?](https://help.leadconnectorhq.com/en/support/solutions/articles/155000000755)

## Casos de uso estándar de campañas

La siguiente tabla contiene la lista de casos de uso estándar de campañas que estarán disponibles en US A2P cuando se lance el registro. Para más detalles, consulte [¿Qué es A2P 10DLC?](https://help.leadconnectorhq.com/en/support/solutions/articles/155000000756)

### Tabla 1: Lista de casos de uso de campaña estándar

| Caso de uso de la campaña (registrado en su servicio de mensajería) | Descripción |
| --- | --- |
| **2FA** | Cualquier tipo de autenticación o verificación de cuenta, como un código OTP. |
| **Notificaciones de cuenta** | Notificaciones sobre el estado de una cuenta o relacionadas con formar parte de una cuenta. |
| **Atención al cliente** | Soporte, gestión de cuentas y otras vías de interacción con el cliente. |
| **Notificaciones de entrega** | Información sobre el estado de una entrega. |
| **Mensajes de alerta de fraude** | Mensajes sobre posibles actividades fraudulentas, como alertas de gastos. |
| **Educación superior** | Campañas de mensajes de colegios, universidades y otras instituciones educativas. |
| **Marketing** | Contenido promocional como rebajas y ofertas por tiempo limitado. |
| **Mezclado** | Una campaña que abarca múltiples casos de uso, como Atención al Cliente y Notificaciones de Entrega. Nota: Las campañas mixtas probablemente tendrán un menor rendimiento y un mayor costo por mensaje. NOTA: Las marcas con bajo volumen de ventas pueden optar al caso de uso mixto de bajo volumen que se detalla a continuación. |
| **Encuestas y votaciones** | Para realizar encuestas y votaciones, como sondeos de clientes. No apto para uso político. |
| **Anuncio de servicio público** | Anuncios de servicio público para aumentar la concienciación del público sobre un tema determinado. |
| **Alerta de seguridad** | Notificación de un sistema comprometido (ya sea por problemas de software o hardware). |

<Warning>
  Las campañas **mixtas** probablemente tendrán un menor rendimiento y un mayor costo por mensaje que una campaña dedicada a un único caso de uso.
</Warning>

## Casos de uso de campañas especiales

Existen algunos casos de uso que las operadoras consideran "especiales", con requisitos adicionales y (en algunos casos) tarifas diferentes. Estos incluyen casos de uso relacionados con organizaciones benéficas/sin fines de lucro 501(c)(3), servicios de emergencia y organizaciones políticas, entre otros.

## Casos de uso de bajo volumen

Además del caso de uso estándar "Mixto/Marketing", existe un caso de uso de campaña independiente denominado **"Mezclado de bajo volumen"**. Esta opción admite los mismos casos de uso múltiples, pero tiene una tarifa mensual más baja que una campaña estándar y está fijada en el [nivel de rendimiento más bajo](https://help.leadconnectorhq.com/en/support/solutions/articles/155000004617) que se indica a continuación, independientemente de su puntuación de confianza.
