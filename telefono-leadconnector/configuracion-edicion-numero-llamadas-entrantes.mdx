## ¿Qué es Editar configuración (Ajustes de llamadas entrantes)?

Esta interfaz rediseñada consolida todos los elementos que pueden interceptar o redirigir una llamada entrante (IVR, desvío, IA, etc.) en una única ventana de fácil lectura. Cada fila muestra (1) si el factor está habilitado, (2) qué registro es el responsable y (3) una acción de edición o un enlace directo para que pueda ajustar la configuración de inmediato. Al visualizar el orden de prioridad, la pantalla elimina las conjeturas cuando una llamada no suena donde espera.

## Principales ventajas de la configuración de llamadas entrantes

| Ventaja | Qué aporta |
| --- | --- |
| **Transparencia total** | Vea exactamente qué regla responderá primero, segundo y tercero. |
| **Edición en línea** | Cambie o actualice la mayoría de las configuraciones sin salir de la página. |
| **Prioridad clara** | Aprenda el orden fijo que sigue el sistema. |
| **Rapidez en la resolución de problemas** | Detecta rápidamente números mal configurados o usuarios que faltan. |
| **Menos llamadas perdidas** | Optimice el enrutamiento para que los clientes potenciales siempre contacten con una persona. |
| **Ahorro de tiempo** | Ya no tendrá que buscar en menús separados para cada función. |

## Acceder a la configuración de edición del número de teléfono

Dirígete a **Configuración \> Números de teléfono \> pestaña Números de teléfono**. En la lista de números de teléfono, haz clic en el menú de tres puntos que aparece junto al número que te interese y, a continuación, haz clic en **Editar configuración**.

## Detalles básicos

En la pestaña **Detalles básicos**:

1. **Nombre descriptivo:** cambie el nombre del número de teléfono.
2. **Las llamadas van a**
   1. **Miembro del equipo:** utilice el menú desplegable para seleccionar al miembro del equipo específico al que se dirigirán las llamadas a este número.
   2. **Opciones de timbre:** seleccione uno o más lugares para que suenen simultáneamente.
      1. **Aplicación web:** si tienen la aplicación web abierta, sonará.
      2. **Aplicación móvil:** si han iniciado sesión en la aplicación móvil, sonará.
      3. **Número de teléfono:** haga clic e ingrese un número específico al que desea desviar la llamada.
      4. **Teléfono de escritorio VoIP:** si está configurado, su teléfono de escritorio físico sonará.
3. **Grabación de llamadas**
   1. **Activar/desactivar la grabación de llamadas:** active o desactive la grabación de llamadas para este número.
   2. **Casilla de mensaje:** márquela para reproducir un mensaje antes de iniciar la llamada.
   3. **Cuadro de mensaje:** escriba el mensaje que desea que se reproduzca (por ejemplo: _Esta llamada se grabará con fines de calidad_).

## Pestaña de desvío de llamadas

En la pestaña **Desvío de llamadas**:

1. **Las llamadas van a**
   1. **IVR:** Si el sistema IVR gestiona el número, ninguna de las demás opciones estará habilitada. Acceda a la configuración del IVR para gestionar el número.
   2. **Miembro del equipo** (PRIMERA PRIORIDAD)
   3. **Número de teléfono externo** (SEGUNDA PRIORIDAD)
   4. **IA de voz** (3.ª PRIORIDAD)
2. **Llamar a más miembros del equipo:** si está marcada, puede seleccionar hasta 6 usuarios más para llamarlos al mismo tiempo.
   1. **Selección múltiple de usuarios:** utilice la selección múltiple para elegir entre 1 y 6 usuarios adicionales.
   2. **Tipo de dispositivo:** el icono del dispositivo que aparece junto al nombre del usuario (ordenador de escritorio, móvil, etc.) muestra qué tipo de dispositivo ha configurado ese usuario para que suene en su dispositivo.
3. **Tiempo de espera:** las llamadas entrantes se desvían al sistema de respaldo después del número de segundos establecido.
   1. **Tiempo de espera para llamadas entrantes:** marque esta casilla para usar este número de segundos para las llamadas entrantes. Edite los segundos en el campo. (Se recomiendan 20 segundos).
   2. **Tiempo de espera para llamadas salientes:** marque esta casilla para usar este número de segundos para las llamadas salientes. Edite los segundos en el campo.
4. **Respaldo**
   1. **IA de voz:** marque esta opción para enviar las llamadas entrantes que hayan caducado a un bot de IA de voz.
   2. **Buzón de voz:** marque esta opción para enviar las llamadas entrantes que no se contesten al buzón de voz de la ubicación.

## Comprender la prioridad del flujo de llamadas

La interfaz de usuario simplificada muestra los factores de arriba a abajo en el orden exacto en que el sistema los evalúa:

| Orden | Factor evaluado |
| --- | --- |
| 1 | Flujo de trabajo, IVR u otra automatización asociada al número |
| 2 | Usuario asignado al número de teléfono |
| 3 | Usuario asignado al registro de contacto |
| 4 | Llamada entrante a varios usuarios (Llamar a todos) |
| 5 | Número de reenvío |

Cada opción tendrá una insignia, como “Prioridad 1”, “Prioridad 2”, etc. Solo sonará una opción. El sistema llamará a la persona con la prioridad más alta disponible. Por ejemplo, si el usuario Andy Anderson tiene prioridad 1, pero no ha iniciado sesión en ningún sistema y no tiene número de teléfono, el sistema verificará la prioridad 2.
