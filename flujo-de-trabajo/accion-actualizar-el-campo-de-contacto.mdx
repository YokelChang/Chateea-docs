## Acción: Actualizar el campo de contacto.

<Info>
  **Documentado el 16 de agosto de 2026.**

  Artículo original modificado el martes, 25 de abril de 2023 a las 10:27 a. m.
</Info>

Este artículo explica las acciones **"Actualizar campo de contacto"** y **"Borrar datos de campo"** de los flujos de trabajo. La primera permite actualizar un campo de contacto con un nuevo valor, ya sea estático o dinámico, mientras que la segunda borra el valor existente de un campo de contacto personalizado. Ambas acciones solo son compatibles actualmente con los campos personalizados de contacto.

## ¿Qué es la acción "Actualizar campo de contacto" en los flujos de trabajo?

La acción "Actualizar campo de contacto" en los flujos de trabajo permite actualizar el valor de un campo específico para un contacto. Con esta acción, puede especificar un nuevo valor para el campo, y el valor existente del contacto se reemplazará por el nuevo. Sin embargo, con esta nueva función, también puede borrar el campo, es decir, vaciar el campo de entrada o restablecerlo a su valor predeterminado.

<Warning>
  **Tenga en cuenta:** es importante tener en cuenta que la función para borrar datos de campo actualmente solo admite los campos personalizados de contacto.
</Warning>

Puedes usar esta acción para actualizar o borrar varios campos con valores estáticos o personalizados en cualquier punto del flujo de trabajo. Los campos se pueden actualizar dinámicamente en los flujos de trabajo dondequiera que se utilicen.

### Actualizar datos de campo (Update Field Data)

Actualiza el campo seleccionado con el valor proporcionado.

La acción "Update Contact Field" en los flujos de trabajo permite actualizar el valor de un campo específico para un contacto. Es útil cuando quieres actualizar un campo con un valor nuevo, como un número de teléfono, una dirección de correo electrónico o un campo personalizado.

Para usar la acción, debes añadirla a tu flujo de trabajo, seleccionar el campo de contacto que quieres actualizar y especificar el nuevo valor que quieres asignarle. Puedes actualizar el campo con:

- un **valor estático**, un valor fijo que especificas en el flujo de trabajo, o
- un **valor personalizado**, generado dinámicamente a partir de otros datos de tu flujo de trabajo.

<Tip>
  **Ejemplo de la fuente:** si tienes un campo personalizado llamado "Lead Source", puedes usar la acción "Update Contact Field" para actualizar el valor de ese campo en un contacto concreto. Puedes ponerle un valor estático como "Website", indicando que el lead llegó desde tu sitio web. O bien, puedes actualizarlo con un valor personalizado generado dinámicamente a partir de la fuente de referencia del lead.
</Tip>

Una vez que la acción "Update Contact Field" se ejecuta en el flujo de trabajo, el valor existente del campo del contacto se reemplaza por el nuevo valor especificado en la acción. Es importante tener en cuenta que puedes usar esta acción para actualizar varios campos con valores estáticos o personalizados en cualquier punto del flujo de trabajo.

### Borrar datos de campo (Clear Field Data)

Restablece el campo seleccionado al valor predeterminado (borra los datos).

Borrar campos de contacto es una función que permite eliminar el valor existente de un campo de contacto, restableciéndolo efectivamente a un valor vacío. Es útil cuando quieres quitar un valor introducido previamente en un campo de contacto. Al usar la función de borrado, el valor del campo del contacto se establece en NULL o vacío.

<Warning>
  **Tenga en cuenta:** es importante señalar que la función de borrado de datos de campo actualmente solo admite los campos personalizados de contacto (Contact Custom Fields). Esto significa que solo puedes borrar los campos personalizados que hayas creado para tus contactos, no campos estándar como el nombre, el apellido o el correo electrónico.
</Warning>

Para borrar un campo de contacto en un flujo de trabajo, añade la acción "Update Contact Field", selecciona el campo de contacto que quieres borrar y añade un filtro para indicar qué campo quieres borrar. Una vez ejecutado el flujo de trabajo, el campo de contacto quedará sin su valor anterior y se establecerá en un valor vacío.

<Warning>
  Es importante usar esta función con precaución, ya que borrar un campo de contacto puede resultar en la pérdida de datos valiosos. Por lo tanto, se recomienda usarla solo cuando sea necesario y asegurarse de tener una copia de seguridad de los datos antes de borrar cualquier campo de contacto.
</Warning>
