En esta guía exploraremos la acción de flujo de trabajo **"Establecer fecha de inicio del evento"**, una herramienta dinámica que permite programar tareas y recordatorios dentro del flujo de trabajo para una gestión precisa de eventos. Esta función es fundamental para mantener bien organizados seminarios web, conferencias o sistemas de notificación personalizados.

## ¿Qué es el paso "Establecer fecha de inicio del evento" en los flujos de trabajo?

<Note>
  **Vídeo próximamente.** El artículo original incluye un vídeo titulado _Event Start Time_. El PDF de origen no expone la URL del vídeo, así que queda marcado aquí para incrustarlo cuando el equipo lo recapture.
</Note>

La acción "Establecer fecha y hora de inicio del evento" es una herramienta dentro de un sistema de gestión de flujos de trabajo que permite definir una fecha y hora específicas que servirán como punto de referencia para los pasos posteriores del flujo de trabajo. Es especialmente útil para programar tareas, recordatorios o acciones que deben realizarse antes o después de un evento en particular.

Una vez configurada esta acción, puede usar los pasos de **"Espera"** en su flujo de trabajo para **pausar** la ejecución hasta una hora específica en relación con la fecha del evento. Por ejemplo, puede configurar recordatorios para que se envíen varios días antes del evento o programar una acción de seguimiento para varios días después.

Esta herramienta ofrece flexibilidad y automatización, lo que permite una gestión eficaz del tiempo dentro de tu flujo de trabajo. Es especialmente útil para gestionar seminarios web, conferencias, reuniones y eventos.

## ¿Cómo utilizar la acción Fecha de inicio del evento?

<Steps>
  <Step title="Paso 1: Agregue la acción Fecha/Hora de inicio del evento a su flujo de trabajo">
    Navega hasta el flujo de trabajo específico que quieras modificar.

    Añade la acción **"Set Event Start Date/Time"** y prepárate para personalizarla.

    <Note>
      **Imagen próximamente.** Captura del constructor de flujos de trabajo con el panel _Actions_ abierto, el buscador con la palabra `event` escrita y la acción **Set Event Start Date** resaltada en la lista de resultados.
    </Note>
  </Step>
  <Step title="Paso 2: Personaliza la fecha y hora de inicio del evento">
    Normalmente tendrás opciones de tipo como **Custom Field**, **Specific Date/Time** o **Specific Day**.

    Para los campos personalizados (**Custom Fields**), puedes usar valores personalizados de tipo Campo de Fecha ya creados para indicarle al flujo de trabajo qué fecha de evento quieres especificar.

    <Note>
      **Imagen próximamente.** Captura del panel **Event Start Date** con el campo _ACTION NAME_ relleno como `Set Event Start Time` y el desplegable _TYPE_ abierto mostrando Custom Field, Specific Date/Time y Specific Day. Una segunda captura muestra el selector _SELECT CUSTOM FIELD_ con las ramas Contact, Custom Values, Date Of Birth y Custom Fields.
    </Note>

    <Warning>
      **Tenga en cuenta:** la acción "Set Event Start Date/Time" suele admitir distintos formatos de fecha y hora. Estos son algunos de los formatos aceptados habitualmente:

      - **MM-DD-YYYY HH:MM** — incluye el mes (MM), el día (DD) y el año (YYYY), seguidos de la hora en formato de 24 horas (HH:MM). Por ejemplo, el 21 de diciembre de 2021 a las 8:30 a. m. se escribiría como `12-21-2021 08:30`.
      - **DD-MMM-YYYY HH:MM** — incluye el día (DD), el mes abreviado (MMM) y el año (YYYY), seguidos de la hora en formato de 24 horas (HH:MM). Por ejemplo, el 21 de octubre de 2021 a las 8:30 a. m. se escribiría como `21-OCT-2021 08:30`.
    </Warning>

    Selecciona la opción que quieras usar y completa la información necesaria. Por ejemplo, si eliges una fecha y hora específicas, tendrás que introducir la fecha y la hora exactas del evento. Guarda la acción para añadirla a tu flujo de trabajo.
  </Step>
  <Step title="Paso 3: Agregar una acción de espera para el evento/hora de la cita">
    Después de establecer la fecha y hora de inicio del evento, añade una acción **"Wait for Event/Appointment Time"** en tu flujo de trabajo.

    Configura la acción para esperar un número determinado de días, horas o minutos antes o después de la fecha y hora de inicio del evento. Por ejemplo, si lo configuras en 2 días antes, el flujo de trabajo esperará y ejecutará la siguiente acción 2 días antes de la fecha de inicio del evento programada.

    <Note>
      **Imagen próximamente.** Captura del panel **Wait** con _WAIT FOR_ en `Event / Appointment time`, la fila _UNTIL_ con los campos When / Months (max: 9999) / Days (max: 30) / Hours (max: 23) / Minutes (max: 59) y las tres opciones de comportamiento cuando la espera ya pasó.
    </Note>

    Guarda la acción para confirmar los cambios.

    Recuerda que estas acciones son repetibles dentro del flujo de trabajo. Puedes añadir varias acciones **"Wait for Event/Appointment Time"** para crear eventos previos o posteriores a la fecha de inicio del evento.
  </Step>
</Steps>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title='P1: ¿Puedo usar la acción "Establecer fecha/hora de inicio del evento" para eventos recurrentes?'>
    Sí, normalmente es posible usar esta acción para eventos recurrentes. Puedes fijar la fecha y hora de inicio del evento para la primera instancia y luego usar una acción **"Go To"** para volver al principio del flujo de trabajo en las instancias siguientes.
  </Accordion>

  <Accordion title="P2: ¿Puedo establecer varias fechas/horas de inicio de eventos en el mismo flujo de trabajo?">
    Normalmente, puedes añadir varias acciones de "Establecer fecha/hora de inicio del evento" dentro del mismo flujo de trabajo. Cada una podría corresponder a un evento o cita diferente, y luego podrías usar los pasos correspondientes de "Esperar a la hora del evento/cita" para crear acciones relativas a cada fecha/hora de inicio.
  </Accordion>

  <Accordion title="P3: ¿Qué sucede si un contacto ingresa al flujo de trabajo después de que haya pasado la fecha y hora de inicio del evento?">
    El comportamiento depende de la configuración de la acción "Esperar a la hora del evento/cita". Si la configura como "Pasar al siguiente paso" o "Pasar a un paso específico", el contacto omitirá la acción de espera. Si la configura como "Omitir todas las acciones de comunicación saliente hasta la siguiente espera o la fecha de inicio del evento", omitirá los pasos de comunicación saliente hasta que encuentre la siguiente espera o la fecha/hora de inicio.
  </Accordion>

  <Accordion title='P4: ¿Puedo usar la acción "Establecer fecha/hora de inicio del evento" sin una acción correspondiente de "Esperar a que comience el evento/la hora de la cita"?'>
    No sería muy útil si técnicamente se pudiera establecer la fecha y hora de inicio de un evento sin una acción posterior de "Esperar a la hora del evento/cita". El propósito principal de la acción "Establecer fecha y hora de inicio del evento" es fijar un punto de referencia al que puedan hacer referencia otras acciones.
  </Accordion>

  <Accordion title='P5: Si la configuración de mi flujo de trabajo está configurada para respetar las zonas horarias de Contacto, ¿cómo afecta eso a la acción "Establecer fecha/hora de inicio del evento"?'>
    Si tu herramienta de gestión de flujos de trabajo admite zonas horarias, normalmente configurarías la fecha y hora de inicio del evento en tu zona horaria, y la herramienta la ajustaría según la zona horaria de cada contacto. Si el flujo de trabajo no dispone de información sobre la zona horaria de un contacto, utilizará por defecto la zona horaria de tu cuenta.
  </Accordion>
</AccordionGroup>
