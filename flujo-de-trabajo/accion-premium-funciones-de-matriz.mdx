## 1. ¿Qué es una función de matriz?

Una función de matriz es una **acción premium** de la automatización de flujos de trabajo diseñada específicamente para manejar datos de matriz (arrays).

Esta funcionalidad resulta muy útil para flujos de trabajo complejos que involucran matrices: listas de productos de un pedido, respuestas de un webhook con varios elementos o cualquier estructura que devuelva más de un objeto.

## 2. ¿Cómo utilizar los tipos de acciones?

<Steps>
  <Step title="Agregar la acción">
    Haz clic en el botón **"\+"** para agregar una acción. Busca **"Funciones de matriz"** (Array Functions) o desplaza hacia abajo hasta la pestaña **Acciones** para seleccionarla.
  </Step>
  <Step title="Seleccionar tipo de acción">
    Después de seleccionar la acción **Función de matriz**, debes elegir el **tipo de acción** en el desplegable **ACTION TYPE**.
  </Step>
</Steps>

## 2.1 Tipo de acción: Buscar

Sirve para encontrar las parejas clave-valor coincidentes en un array de objetos y devolver el objeto.

**Seleccione un campo.** Aquí se enumeran todos los campos con tipo de datos de matriz disponibles en el flujo de trabajo. La lista de datos de matriz disponibles se obtiene de:

- los activadores de **Shopify**,
- el activador de **webhook entrante**,
- los datos de respuesta de **acciones de webhook personalizadas**.

En el siguiente ejemplo se utiliza el activador de **pedido realizado de Shopify** y se comprueba si un producto con el ID de producto `zGhad23wfadfa` forma parte de los artículos de línea de Shopify.

<Steps>
  <Step title="Seleccione Shopify → Artículos de línea">
    En **SELECT FIELD**, despliega el grupo **Shopify** y elige **Line Items**.
  </Step>
  <Step title="Seleccione clave-valor para encontrar el objeto coincidente">
    En el bloque **FILTERS**, elige la clave (**Key**) y escribe el valor (**Value**).
  </Step>
  <Step title="Introduzca el valor para encontrar la coincidencia">
    Por ejemplo, clave `id` y valor `zGhad23wfadfa`.
  </Step>
  <Step title="Agregar otro elemento (opcional)">
    También puedes encontrar el objeto coincidente con varios pares clave-valor agregando otro elemento clave-valor con **Add another item**.
  </Step>
</Steps>

## 2.2 Tipo de acción: Filtro

Selecciona el tipo de acción **"Filtrar"** en el menú desplegable. Este tipo de acción te ayudará a filtrar la matriz haciendo coincidir los pares clave-valor en una matriz de objetos.

**Caso de uso:** filtra el array por grupo de productos y luego envíalo a través de un **webhook personalizado**.

<Steps>
  <Step title="Seleccione el campo de matriz">
    En **SELECT FIELD** se enumeran todos los campos con tipo de datos de matriz disponibles en el flujo de trabajo (Shopify, webhook entrante y respuestas de webhooks personalizados). Selecciona **Shopify → Artículos de línea**.
  </Step>
  <Step title="Seleccione el valor de la clave">
    Elige la clave por la que quieres filtrar; se mostrará la lista de variables clave del campo de matriz seleccionado.
  </Step>
  <Step title="Introduzca el valor para encontrar la coincidencia">
    Puedes escribir un valor fijo o insertar una variable, como `{{user.name}}`.
  </Step>
  <Step title="Agregar otro elemento (opcional)">
    También puedes encontrar los objetos coincidentes con varios pares clave-valor agregando otro elemento clave-valor.
  </Step>
</Steps>

<Tip>
  La diferencia clave con **Find**: **Find** devuelve **un** objeto y **Filter** devuelve **una matriz** con todos los objetos que cumplen la condición.
</Tip>

## 2.3 Tipo de acción: Buscar por índice

Selecciona el tipo de acción **"Buscar por índice"** en el menú desplegable. Este tipo de acción te ayudará a encontrar los datos del índice de la matriz.

1. En **SELECT FIELD** se enumeran todos los campos con tipo de datos de matriz disponibles en el flujo de trabajo. Selecciona **Shopify → Artículos de línea**.
2. Escribe el **INDEX** que quieres recuperar. Se devolverá el valor del índice introducido.

<Warning>
  Los índices empiezan en **0**: el primer elemento de la matriz es el índice `0`, el segundo es el `1`, y así sucesivamente. Si el índice solicitado no existe en la matriz, no habrá objeto que devolver.
</Warning>

## 2.4 Tipo de acción: Partidas individuales

Selecciona el tipo de acción **"Elementos de línea"** (Line Items) en el menú desplegable. Este tipo de acción ayudará a reconstruir una matriz con **claves personalizadas**.

**Casos de uso:**

- Reconstruir la estructura del array antes de enviarlo a través de un webhook personalizado.
- Reconstruir la matriz antes de almacenarla en Google Sheets (**Crear filas**).
- Reconstruir la matriz para que coincida con la estructura del carrito de compras del **Email Builder**.

<Steps>
  <Step title="Seleccione el campo de matriz">
    En **SELECT FIELD**, elige **Shopify → Artículos de línea**.
  </Step>
  <Step title="Defina las claves personalizadas">
    En el bloque **FIELDS**, introduce el valor personalizado en el campo de entrada **"Clave"** (Key) y selecciona el valor correspondiente en el menú desplegable de valores (**Value**).
  </Step>
  <Step title="Agregar otro elemento (opcional)">
    Agrega tantos pares clave-valor como necesite la estructura de destino.
  </Step>
</Steps>

## 2.5 Tipo de acción: Matemáticas

Selecciona el tipo de acción **"Matemáticas"** (Math Functions) en el menú desplegable. Este tipo de acción te ayudará a calcular la suma, el mínimo, el máximo y el promedio mediante la comparación de pares clave-valor en una matriz de objetos.

**Caso de uso:** calcular el subtotal (total del artículo), artículos en el carrito (cantidad) y artículos totales (cantidad).

<Steps>
  <Step title="Seleccione el campo de matriz">
    En **SELECT FIELD**, elige **Shopify → Artículos de línea**.
  </Step>
  <Step title="Seleccione la clave">
    Elige la clave sobre la que se hará el cálculo (por ejemplo, `quantity`). Se mostrará la lista de variables clave del campo de matriz seleccionado.
  </Step>
  <Step title="Marque las operaciones">
    Selecciona o deselecciona de la lista de opciones disponibles en el bloque **OPERATIONS**.
  </Step>
</Steps>
