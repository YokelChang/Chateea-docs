## Funciones de matriz

Para manejar datos de matriz en el flujo de trabajo.

La acción **Array Functions** ofrece métodos para trabajar con listas provenientes de distintos orígenes dentro del flujo.

## Seleccionar tipo de acción

Antes de configurar nada más, elige el tipo de acción en el desplegable **ACTION TYPE**.

## Tipo de acción: Buscar

Para encontrar las claves-valores coincidentes en una matriz de objetos y devolver el objeto.

Al seleccionar **Find**, el panel muestra la ayuda _Returns object that matches key-value_ y añade el campo **SELECT FIELD**.

### Seleccione un campo

Aquí se enumeran todos los campos con tipo de datos de matriz disponibles en el flujo de trabajo. La lista de datos de matriz disponibles se obtiene de los activadores de **Shopify**, el activador de **webhook entrante** y los datos de respuesta de **acciones de webhook personalizadas**.

En el siguiente ejemplo se utiliza el activador de **pedido realizado de Shopify** y se comprueba si un producto con el ID de producto `zGhad23wfadfa` forma parte de los artículos de la línea de Shopify.

<Steps>
  <Step title="Seleccione Shopify > Artículos">
    Despliega el grupo **Shopify** dentro de **SELECT FIELD** y elige **Line Items**.
  </Step>
  <Step title="Seleccione clave-valor para encontrar el objeto coincidente">
    En el bloque **FILTERS** aparecen los campos **Key** y **Value**.
  </Step>
  <Step title="Seleccionar tecla">
    Se muestra la lista de variables clave del campo de matriz seleccionado. En este ejemplo, las claves de los artículos de línea de Shopify.
  </Step>
  <Step title="Introduzca el valor para encontrar la coincidencia">
    Por ejemplo: clave `id`, valor `zGhad23wfadfa`.
  </Step>
  <Step title="Agregar otro artículo">
    También puedes encontrar el objeto coincidente con múltiples pares clave-valor agregando otro elemento clave-valor con **Add another item**.
  </Step>
</Steps>

## Usar las variables devueltas

Al completar los pasos anteriores, ya puedes usar las variables de objeto devueltas por la función **Array** como valores personalizados en correos electrónicos, SMS, sentencias condicionales (**if/else**), etc. En el menú de valores personalizados aparecen agrupadas bajo **Array Functions**, junto al número del paso que las generó (por ejemplo, `#2 Array Functions`).
