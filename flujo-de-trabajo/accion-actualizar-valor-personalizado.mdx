## Acción: Actualizar valor personalizado

<Info>
  **Documentado el 16 de agosto de 2026.**

  Artículo original modificado el viernes, 5 de mayo de 2023 a las 00:40.
</Info>

La acción de flujo de trabajo **"Actualizar valor personalizado"** es una potente herramienta que automatiza la actualización de valores personalizados en un CRM. Gracias a su capacidad para actualizar valores personalizados a nivel de subcuenta, esta acción tiene un gran impacto en la gestión y automatización de servicios recurrentes, la administración de suscripciones y mucho más.

## ¿Qué es la acción Actualizar valor personalizado en los flujos de trabajo?

La acción de flujo de trabajo "Actualizar valor personalizado" en un CRM se utiliza para actualizar los valores de los campos personalizados en una subcuenta, lo que puede tener un impacto mucho mayor que la simple actualización del campo personalizado de un contacto individual.

Los valores personalizados son marcadores de posición establecidos a nivel de subcuenta y se pueden usar para almacenar y realizar un seguimiento de diversos tipos de información. Esta acción puede automatizar la actualización de dichos valores y activar acciones en función de los valores actualizados.

<Tip>
  **Diferencia clave:** "Actualizar campo de contacto" cambia el dato de una sola persona; "Actualizar valor personalizado" cambia un dato compartido por toda la subcuenta, así que todos los flujos, correos y SMS que usen ese valor pasarán a mostrar el nuevo contenido.
</Tip>

## ¿Cómo utilizar esta acción?

Para usar la acción de flujo de trabajo Actualizar valor personalizado debe tener una plataforma CRM que admita esta función. Una vez que tenga acceso a la plataforma, siga estos pasos:

<Steps>
  <Step title="Paso 1: Crea un nuevo flujo de trabajo o edita uno existente">
    En tu cuenta, entra en **Automation \> Workflows** y crea un flujo de trabajo nuevo con **\+ Create Workflow**, o selecciona uno existente para editarlo.

    <Note>
      **Imagen próximamente.** Captura de la pantalla **Workflow List** con el menú lateral (Launchpad, Dashboard, Conversations, Calendars, Contacts, Opportunities, Payments, Marketing, Automation, Sites, Reputation, Reporting), la pestaña _Workflows_ resaltada y el botón **\+ Create Workflow**.
    </Note>
  </Step>
  <Step title="Paso 2: Agregue la acción Actualizar valor personalizado">
    Añade la acción **Update Custom Value** desde la lista de acciones disponibles dentro del flujo de trabajo.

    <Note>
      **Imagen próximamente.** Captura de la tarjeta de la acción **Update Custom Value** tal como aparece en el listado de acciones.
    </Note>
  </Step>
  <Step title="Paso 3: Elija el valor personalizado que desea actualizar">
    Selecciona el valor personalizado que quieres actualizar de la lista de valores disponibles —por ejemplo: Notifications Email For Client, Offer Name, SMS or Email, testtest, Twilio Number, Twilio Number In link Form, Your App Login URL—.

    El panel muestra tres campos:

      </tr>
    </thead>

    <tbody>
      <tr style={{ background: "rgba(58,221,143,0.06)" }}>

    **Especifica el nuevo valor:** introduce el nuevo valor al que quieres actualizar el valor personalizado. Puedes actualizarlo con un valor estático, un valor fijo que especificas en el flujo de trabajo, o un valor personalizado, generado dinámicamente a partir de otros datos de tu flujo de trabajo.

    <Note>
      **Imagen próximamente.** Capturas del panel **Update Custom Value** con el desplegable _CUSTOM VALUE_ abierto mostrando la lista de valores, y del panel con CURRENT VALUE en `sms` y NEW VALUE en `email`.
    </Note>
  </Step>
  <Step title="Guarda, prueba y publica">
    - **Guarda la acción:** guarda la acción y cualquier otra acción o condición que quieras añadir al flujo de trabajo.
    - **Prueba el flujo de trabajo:** compruébalo para asegurarte de que funciona como esperas. Puedes hacerlo activando el flujo con un contacto de prueba o configurando un entorno de prueba con el botón **Test Workflow**.
    - **Publica el flujo de trabajo:** cuando estés conforme, publícalo para que pueda activarse automáticamente según las condiciones establecidas.
  </Step>
</Steps>

<Warning>
  Revisa el flujo de trabajo antes de ejecutarlo. Un valor personalizado actualizado por error afecta a toda la subcuenta y **no se puede deshacer**.
</Warning>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="P: ¿Puedo usar la acción Actualizar valor personalizado junto con otras acciones en un flujo de trabajo?">
    Sí, la acción Actualizar valor personalizado se puede usar con otras acciones en un flujo de trabajo. Por ejemplo, puede usarla con una acción de desencadenador para actualizar un campo de valor personalizado cuando ocurre un evento específico.
  </Accordion>

  <Accordion title="P: ¿Puedo actualizar varios valores personalizados usando la acción Actualizar valor personalizado?">
    Puede actualizar varios valores personalizados utilizando la acción Actualizar valor personalizado agregando pasos de acción adicionales a su flujo de trabajo.
  </Accordion>

  <Accordion title="P: ¿Con qué frecuencia puedo actualizar un valor personalizado usando esta acción?">
    Puede actualizar un valor personalizado con la frecuencia que necesite. No existen límites en cuanto a la frecuencia con la que puede actualizar un valor personalizado mediante esta acción.
  </Accordion>

  <Accordion title="P: ¿Puedo usar la acción Actualizar valor personalizado para actualizar valores personalizados de forma masiva?">
    Puedes usar la acción Actualizar valor personalizado para actualizar varios valores personalizados a la vez. Sin embargo, para ello necesitarás varias acciones Actualizar valor personalizado, ya que cada una actualiza un único valor personalizado.
  </Accordion>

  <Accordion title="P: ¿Puedo usar la acción Actualizar valor personalizado para actualizar valores personalizados para diferentes subcuentas?">
    Sí, puede usar la acción Actualizar valor personalizado para actualizar los valores personalizados de distintas subcuentas con valores diferentes. Actualice los valores personalizados en la subcuenta que sea la cuenta maestra utilizada para crear una instantánea de sus cuentas vinculadas. Una vez actualizados los valores personalizados, actualice la instantánea y cárguela en las cuentas vinculadas.
  </Accordion>

  <Accordion title="P: ¿Puedo usar variables en la acción Actualizar valor personalizado?">
    Puedes usar variables en la acción Actualizar valor personalizado para actualizar dinámicamente valores personalizados en función de otros datos. Esto te permite crear flujos de trabajo más complejos que responden a los cambios en tus datos.
  </Accordion>

  <Accordion title="P: ¿Puedo deshacer una actualización realizada con la acción Actualizar valor personalizado?">
    No, no se puede deshacer una vez que se ha actualizado un valor personalizado mediante la acción Actualizar valor personalizado. Es importante revisar cuidadosamente el flujo de trabajo antes de ejecutarlo para evitar actualizaciones no deseadas.
  </Accordion>
</AccordionGroup>
