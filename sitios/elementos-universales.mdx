Los elementos universales te permiten diseñar un elemento una sola vez y reutilizarlo en embudos, sitios web, blogs, seminarios web y páginas de tienda, manteniendo todas las copias sincronizadas. Si cambias el botón principal de tu marca o tu logotipo, lo editas en un lugar, publicas las páginas afectadas y el cambio aparece en todas. Es la forma más sencilla de mantener la coherencia visual cuando tienes muchas páginas o varias personas construyendo.

## Qué son

Un elemento universal es un elemento individual (un botón, un logotipo, un icono, un menú) que guardas en la biblioteca de **Recursos guardados** y que queda **vinculado** en cada página donde lo colocas. Cuando actualizas ese elemento y publicas, todas las instancias reflejan el cambio.

## Ventajas

- **Coherencia de marca:** tipografías, colores y estilos iguales en todas tus páginas sin retocarlas una por una.
- **Construcción más rápida:** arrastras el elemento desde la biblioteca en lugar de rediseñarlo.
- **Actualizaciones centralizadas:** editas una vez y publicas las páginas afectadas.
- **Biblioteca ordenada:** miniaturas y búsqueda para encontrar lo que usas a menudo.
- **Trabajo en equipo:** todos construyen con los mismos componentes aprobados.

## Elementos universales, plantillas de elemento y secciones universales

Chateea ofrece varias formas de guardar y reutilizar contenido. Elegir la correcta evita confusiones y cambios de diseño accidentales.

| Tipo guardado | Alcance | Sincronización | Usos típicos | Dónde encontrarlo |
| --- | --- | --- | --- | --- |
| **Elementos universales** | Un elemento | Vinculado. Los cambios aparecen en las instancias al publicar las páginas afectadas. | Botones, logotipos, iconos, menús | Recursos guardados → **Elementos universales** |
| **Plantillas de elemento** | Un elemento | Se inserta como copia. Los cambios posteriores **no** se sincronizan. | Variantes únicas, puntos de partida rápidos | Recursos guardados → **Plantillas de elemento** |
| **Secciones universales** | Una sección completa | Vinculada a nivel de sección. Los cambios se sincronizan al publicar. | Encabezados, pies de página, barras de anuncios | Recursos guardados → **Secciones** (universales) |

<Tip>
Usa elementos universales para piezas pequeñas que se repiten, como botones o insignias. Usa secciones universales cuando necesites reutilizar un bloque completo, como el encabezado o el pie de página.
</Tip>

## Cómo crear un elemento universal

Guardarlo bien desde el principio asegura que quede como elemento **vinculado** y no como una plantilla que no se sincroniza.

<Steps>
<Step title="Abre una página en el creador">
Puede ser una página de embudo, sitio web, blog, seminario web o tienda.
</Step>
<Step title="Guarda el elemento como universal">
Selecciona el elemento que quieres reutilizar y guárdalo como **Elemento universal** desde cualquiera de estos lugares:
- La barra de herramientas del elemento → icono **Guardar**.
- El panel **Capas** → menú **⋯** → **Guardar como elemento universal**.
</Step>
<Step title="Ponle un nombre claro">
Usa un nombre fácil de buscar, por ejemplo `Botón - CTA principal`.
</Step>
<Step title="Confirma">
El elemento aparece en **Recursos guardados → Elementos universales** con su miniatura.
</Step>
</Steps>

## Cómo colocar y editar un elemento universal

**Para colocarlo:**

1. Abre **Agregar elementos → Recursos guardados → Elementos universales**.
2. Busca por nombre o navega por las miniaturas y arrastra el elemento al lienzo.

Colocarlo siempre desde la biblioteca garantiza que cada instancia quede vinculada.

**Para editarlo:**

1. Selecciona una instancia colocada y ajusta su diseño o configuración.
2. Guarda los cambios de la página.
3. **Publica** la página para que los visitantes vean la actualización.

<Warning>
Como el elemento está vinculado, un cambio afecta a todas las páginas donde se usa. Si necesitas una variante solo para una página, conviértelo antes en una copia local no vinculada o usa una plantilla de elemento.
</Warning>

### Cuando editas páginas con IA

Las revisiones de página con IA están pensadas para respetar los elementos universales vinculados y centrarse en el contenido que les pediste cambiar. Aun así:

- Comprueba si la zona que vas a revisar incluye un elemento universal vinculado antes de lanzar la revisión.
- Si necesitas una variante solo para esa página, duplica el elemento como copia local antes de revisar.
- Revisa el resumen que aparece después de la revisión para confirmar si se modificó algún elemento vinculado, y publica los cambios globales solo cuando los hayas validado.

## Cómo mantener ordenada la biblioteca

- **Busca y navega:** en **Agregar elementos → Recursos guardados → Elementos universales** tienes miniaturas y búsqueda por palabra clave.
- **Usa prefijos coherentes:** por ejemplo `Botón -`, `Icono -`, `Menú -`.
- **Elimina con cuidado:** borrar un elemento guardado lo quita de la biblioteca para usos futuros. Revisa antes qué páginas dependen de él.

## Preguntas frecuentes

<AccordionGroup>
<Accordion title="¿Tengo que publicar para que los visitantes vean los cambios?">
Sí. Guardar conserva los cambios en el creador. Publicar las páginas afectadas los hace visibles.
</Accordion>
<Accordion title="¿Dónde encuentro mis elementos universales?">
En el creador, en **Agregar elementos → Recursos guardados → Elementos universales**.
</Accordion>
<Accordion title="¿Puedo renombrar o eliminar un elemento universal?">
Puedes renombrarlo cuando quieras. Si lo eliminas, deja de estar disponible en la biblioteca para usos futuros, así que revisa antes las páginas que lo usan.
</Accordion>
<Accordion title="¿Y si necesito una variante en una sola página?">
Coloca una plantilla de elemento o crea una copia local para que tus cambios no afecten a otras páginas.
</Accordion>
<Accordion title="¿Cómo revierto un cambio que salió mal?">
Usa el **Historial de versiones** de la página afectada para restaurar una versión anterior y vuelve a publicar.
</Accordion>
</AccordionGroup>
