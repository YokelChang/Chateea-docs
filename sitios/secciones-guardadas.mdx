Las secciones guardadas te permiten crear una sección una sola vez (un encabezado, un pie de página, un bloque de testimonios, un formulario de contacto) y reutilizarla en tus embudos, sitios web, seminarios web y tiendas. Según el tipo que elijas, los cambios se sincronizan en toda tu cuenta, solo dentro de un embudo o sitio, o no se sincronizan en absoluto.

## Los tres tipos de sección guardada

| Tipo | Dónde se sincroniza | Úsalo para |
| --- | --- | --- |
| **Universal** | En toda tu cuenta: embudos, sitios web, blogs, seminarios web y tiendas | Contenido que debe ser idéntico en todas partes, como el encabezado o el pie de página de tu marca |
| **Global** | Solo dentro del embudo o sitio web donde la creaste | Contenido que se repite en varias páginas de un mismo proyecto |
| **Plantilla** | No se sincroniza: cada vez que la insertas se crea una copia independiente | Bloques que quieres reutilizar como punto de partida y personalizar en cada página |

<Note>
La diferencia clave: una sección **universal** se actualiza en cada lugar de tu cuenta donde la usas; una sección **global** solo se actualiza dentro del embudo o sitio al que pertenece.
</Note>

## Ventajas

- **Actualizaciones centralizadas**: cambias el pie de página una vez y se actualiza en todas las páginas que lo usan.
- **Reutilización flexible**: eliges si quieres sincronización o una copia estática.
- **Selección visual**: cada sección guardada tiene una vista previa automática y una etiqueta que indica su tipo.
- **Copias independientes**: al clonar una sección, recibe un ID nuevo y sus cambios no afectan al original.
- **Privacidad**: solo se guarda el diseño de la sección, no datos personales.

## Cómo guardar una sección

<Steps>
  <Step title="Abre el editor de páginas">
    Entra al embudo, sitio web, seminario web o tienda y abre la página en el editor.
  </Step>
  <Step title="Selecciona la sección">
    Haz clic en la sección que quieres reutilizar.
  </Step>
  <Step title="Guarda la sección">
    Haz clic en **Guardar sección** (Save Section). Se abre una ventana para configurar el guardado.
  </Step>
  <Step title="Ponle nombre y elige el tipo">
    Escribe un nombre descriptivo y elige **Universal**, **Global** o **Plantilla**. Revisa la vista previa antes de confirmar.
  </Step>
  <Step title="Insértala en otra página">
    Cuando edites otra página, usa **Agregar sección** (Add Section) y busca tus secciones guardadas para insertarlas.
  </Step>
</Steps>

<Warning>
Una vez guardada, el tipo de la sección no se puede cambiar. Si necesitas otro tipo, clona la sección y guarda la copia con el tipo correcto.
</Warning>

## Buenas prácticas

- Decide el tipo antes de guardar, porque luego no podrás cambiarlo.
- Usa secciones **universales** para elementos de marca que deben ser iguales en todas partes (encabezados, pies de página, avisos legales).
- Usa secciones **globales** para contenido propio de un embudo o sitio concreto.
- Usa **plantillas** para bloques que vas a adaptar en cada página.
- Revisa todas las páginas afectadas antes de publicar un cambio en una sección universal.

## Secciones guardadas y revisiones con IA

Si usas la IA para revisar una página que contiene secciones guardadas, el alcance que elijas importa:

- **Una sola sección como objetivo**: la revisión solo debería modificar esa sección.
- **Cambios de estilo en toda la página**: pueden afectar a varias secciones, incluidas las guardadas (por ejemplo, si la IA cambia la tipografía o los colores generales).
- **Secciones universales o globales**: si la IA edita una sección sincronizada, el cambio se propagará a las demás páginas donde aparece cuando publiques.
- **Plantillas**: los cambios se quedan en la página actual.

<Tip>
Si quieres una variante solo para una página, inserta la sección como **Plantilla** (o clónala) y pide a la IA que revise esa copia. Después de cada revisión, lee el resumen de cambios para confirmar que no se tocaron otras secciones.
</Tip>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Puedo cambiar el tipo de una sección después de guardarla?">
    No. Clona la sección y guarda la copia con el tipo que necesitas.
  </Accordion>
  <Accordion title="¿Puedo restaurar una versión anterior de una sección global o universal?">
    No. Las secciones guardadas no tienen historial de versiones: una vez editadas, la versión anterior no se puede recuperar.
  </Accordion>
  <Accordion title="Restauré una versión antigua de la página, ¿por qué la sección sigue mostrando los cambios recientes?">
    Las secciones globales y universales siempre muestran su última versión guardada. Restaurar la página no restaura una versión antigua de la sección.
  </Accordion>
  <Accordion title="¿Los cambios en una sección universal se aplican en todas partes?">
    Sí. Se sincronizan en todos tus embudos, sitios web, blogs, seminarios web y tiendas donde esté insertada.
  </Accordion>
  <Accordion title="¿Qué pasa si clono una sección?">
    La copia recibe un ID nuevo y deja de sincronizarse con la original.
  </Accordion>
  <Accordion title="¿Qué pasa si clono una página que tiene secciones globales o universales?">
    La página clonada conserva los mismos IDs de sección, así que los cambios se siguen sincronizando. Si quieres independizarla, clona la sección en sí.
  </Accordion>
</AccordionGroup>
