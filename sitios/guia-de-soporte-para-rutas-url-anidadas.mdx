Las rutas URL anidadas te permiten organizar tus páginas con direcciones jerárquicas, usando barras (/) como si fueran carpetas. En lugar de `/oferta-black-friday`, puedes tener `/campanas/navidad/oferta-black-friday`. Funcionan en embudos, sitios web, tiendas en línea y seminarios web, y ayudan tanto a tus visitantes como a los buscadores a entender la estructura de tu sitio.

<Note>
Esta función está en fase beta y puede recibir mejoras.
</Note>

## Ejemplos de rutas anidadas

```text
/recursos/cursos/embudo-de-ventas
/seminarios/2026/sesion-de-verano
/campanas/navidad/oferta-black-friday
/lanzamiento/producto-nuevo/paso-1
```

## Ventajas

- **Mejor SEO**: una estructura clara y jerárquica ayuda a los buscadores a indexar y entender tu contenido.
- **Mejor experiencia**: el visitante ve direcciones ordenadas y fáciles de leer en la barra del navegador.
- **Edición flexible**: puedes crear páginas y pasos con varios segmentos, ideal para catálogos, secciones de contenido o embudos de varios pasos.
- **Mapas del sitio correctos**: tu sitemap refleja las rutas anidadas, lo que facilita la indexación en Google.
- **Consistencia**: funciona igual en embudos, sitios web, tiendas y seminarios web.

## Cómo crear una ruta anidada

<Steps>
  <Step title="Abre la página o paso">
    Ve a **Sitios** y abre el embudo, sitio web, tienda o seminario web. Elige la página o paso.
  </Step>
  <Step title="Edita la ruta">
    Haz clic en **Editar** en los detalles de la página o paso.
  </Step>
  <Step title="Escribe la ruta con barras">
    En el campo de ruta, escribe la estructura que quieras usando `/` entre cada nivel, por ejemplo `/blog/marketing/consejos-seo`. Guarda los cambios.
  </Step>
</Steps>

<Info>
Antes, al escribir una barra en la ruta, se convertía automáticamente en guion para crear una ruta plana. Ahora las barras se conservan para que puedas crear una jerarquía real.
</Info>

## Límites y restricciones

### Profundidad máxima

Puedes usar hasta **5 niveles**, por ejemplo `/nivel1/nivel2/nivel3/nivel4/nivel5`. Cada segmento entre barras cuenta como un nivel; el dominio y el subdominio no cuentan. Si intentas guardar una ruta más profunda, el editor bloquea el guardado y muestra el mensaje "URL path is too deep. Maximum 5 levels allowed."

### Rutas reservadas

Estas rutas están reservadas para funciones del sistema y no puedes usarlas. Si lo intentas, verás un mensaje de error.

| Ruta | Reservada para |
| --- | --- |
| `/b/` | Blogs |
| `/c/` | Categorías |
| `/product/` | Páginas de producto |
| `/collections/` | Colecciones |
| `/post/` | Entradas del blog |
| `/category/` | Páginas de categoría |
| `/author/` | Páginas de autor |
| `/tag/` | Páginas de etiquetas |
| `/store/account` | Cuenta de la tienda |

## Buenas prácticas

- **Sin barra final**: usa `/ruta/subruta`, no `/ruta/subruta/`.
- **Sin barras dobles ni segmentos vacíos**: usa `/categoria/articulo`, no `/categoria//articulo`.
- **Minúsculas, números y guiones**: evita mayúsculas y espacios.
- **Rutas descriptivas**: `/blog/consejos-seo` es mejor que `/b/123`.
- **Orden lógico**: haz que la estructura refleje la navegación de tu sitio.
- **Palabras clave**: rutas bien anidadas y con palabras relevantes ayudan al posicionamiento.

<Warning>
Si cambias la ruta de una página que ya está publicada, los enlaces antiguos dejarán de funcionar. Configura una redirección 301 desde la dirección anterior a la nueva para conservar el posicionamiento y evitar errores 404.
</Warning>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="Antes mis barras se convertían en guiones, ¿por qué ya no pasa?">
    Con las rutas anidadas, las barras se conservan para que puedas crear una estructura de carpetas real.
  </Accordion>
  <Accordion title="¿Cambiar una URL publicada rompe los enlaces existentes?">
    Sí. Crea una redirección 301 desde la dirección antigua para no perder posicionamiento ni tráfico.
  </Accordion>
  <Accordion title="¿Puedo usar mayúsculas o espacios?">
    No es recomendable. Usa minúsculas, números y guiones para tener rutas limpias y fáciles de rastrear.
  </Accordion>
  <Accordion title="¿Puedo usar guiones o números dentro de cada segmento?">
    Sí. Rutas como `/blog/2026/novedades-de-julio` o `/curso/leccion-1` son válidas.
  </Accordion>
  <Accordion title="¿Puedo combinar rutas anidadas y planas en el mismo sitio?">
    Sí. Puedes tener `/nosotros` en un solo nivel y `/blog/tema/articulo` anidada dentro del mismo sitio o embudo.
  </Accordion>
</AccordionGroup>
