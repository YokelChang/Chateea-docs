Las páginas de WordPress creadas con el generador de IA de Chateea se pueden editar directamente desde la vista previa en Chateea, sin abrir Elementor. Seleccionas un texto o una imagen, lo cambias a mano o con ayuda de la IA, y guardas. Es la forma más rápida de corregir datos, afinar textos o cambiar una imagen, y Elementor sigue disponible cuando necesitas cambios de diseño más profundos.

## Para qué te sirve

- **Editas más contenido:** títulos, párrafos, botones, cajas de íconos e imágenes de toda la página.
- **Menos saltos entre herramientas:** haces los cambios rutinarios sin abrir Elementor.
- **Escritura asistida por IA:** reformulas, acortas, amplías o cambias el tono del texto seleccionado.
- **Imágenes individuales:** regeneras una imagen sin reconstruir la página.
- **Revisas antes de guardar:** previsualizas los cambios antes de aplicarlos.

## Requisitos

- Una página de WordPress creada con el [generador de páginas con IA](/sitios/generador-de-paginas-con-ia-wordpress).
- El plugin de Chateea para WordPress en la **versión 4.0.4 o superior**.

En los sitios de WordPress nuevos alojados en Chateea, el plugin se instala automáticamente. Puedes revisar el estado de la conexión del plugin desde **Sitios → WordPress**.

## Elementos que puedes editar

| Elemento | Qué puedes cambiar |
| --- | --- |
| **Títulos** | Encabezados de la página y de cada sección |
| **Párrafos** | Descripciones y textos largos |
| **Botones** | El contenido del botón |
| **Títulos de cajas de ícono** | El encabezado asociado a una caja de ícono |
| **Descripciones de cajas de ícono** | El texto debajo de una caja de ícono |
| **Imágenes** | Reemplazar o regenerar la imagen |

<Note>
  No todos los elementos de Elementor se pueden editar desde la vista previa. Si no puedes seleccionar un elemento, edítalo en Elementor.
</Note>

## Editar una página generada con IA

<Steps>
  <Step title="Abre la página">
    Ve a **Sitios → WordPress → Todos los sitios**, abre tu sitio, entra a **Páginas** y abre la página generada con IA que quieres cambiar.
  </Step>
  <Step title="Selecciona un elemento">
    Pasa el cursor sobre la vista previa y haz clic en el texto o la imagen que quieres cambiar. A la derecha se abre el panel **Personalizaciones** (Customizations) con su contenido actual.
  </Step>
  <Step title="Edita el texto">
    Cambia el texto a mano o usa las opciones de IA: **Reformular**, **Acortar**, **Ampliar** o **Cambiar tono**. Revisa el resultado antes de aceptarlo.
  </Step>
  <Step title="Cambia una imagen si hace falta">
    Selecciona la imagen, abre sus opciones de regeneración, escribe o ajusta la descripción de la imagen que quieres, genera el reemplazo y revísalo antes de aplicarlo.
  </Step>
  <Step title="Previsualiza">
    Haz clic en **Vista previa de cambios** (Preview Changes) y revisa que el texto sea correcto, que el tono encaje, que el espaciado se vea bien y que la imagen quede en su lugar.
  </Step>
  <Step title="Guarda">
    Haz clic en **Guardar cambios**. Tus cambios se aplican a la página de WordPress.
  </Step>
</Steps>

Repite el proceso con cada texto o imagen que quieras cambiar.

## Opciones de escritura con IA

| Opción | Qué hace |
| --- | --- |
| **Reformular** | Reescribe el texto con otras palabras |
| **Acortar** | Crea una versión más breve |
| **Ampliar** | Agrega más detalle al texto actual |
| **Cambiar tono** | Reescribe con otro estilo: **Profesional**, **Amigable**, **Persuasivo** o **Seguro** |

<Tip>
  Elige un tono y mantenlo en toda la página. Mezclar un encabezado persuasivo con párrafos muy formales hace que la página se sienta desordenada.
</Tip>

## Cuándo usar Elementor

| Usa la vista previa de Chateea para | Usa **Editar en Elementor** para |
| --- | --- |
| Actualizar textos | Reorganizar la estructura de la página |
| Afinar el texto generado | Trabajar con elementos que no se pueden seleccionar en la vista previa |
| Cambiar el tono | Hacer ajustes de diseño detallados |
| Regenerar imágenes | Cambiar estilos avanzados o la configuración de widgets |

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Puedo editar cualquier elemento de la página?">
    No. Solo los elementos compatibles. Si un elemento no se puede seleccionar desde la vista previa, edítalo en Elementor.
  </Accordion>
  <Accordion title="¿Todavía necesito Elementor?">
    No para la mayoría de los cambios rutinarios de contenido. Elementor sigue disponible para cambios de estructura, estilos avanzados y elementos no compatibles.
  </Accordion>
  <Accordion title="No veo los controles de edición. ¿Por qué?">
    Confirma que estás en una página generada con IA y que el plugin de Chateea para WordPress está en la versión 4.0.4 o superior.
  </Accordion>
  <Accordion title="¿Cuál es la diferencia entre Vista previa de cambios y Guardar cambios?">
    La vista previa te deja revisar la página antes de confirmar. Guardar cambios aplica la edición a la página.
  </Accordion>
  <Accordion title="¿Puedo seguir editando en Elementor después?">
    Sí. La página se puede abrir y editar en Elementor en cualquier momento.
  </Accordion>
</AccordionGroup>
