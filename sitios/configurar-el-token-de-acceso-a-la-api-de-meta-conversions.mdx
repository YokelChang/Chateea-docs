La API de conversiones de Meta envía los eventos de tu sitio directamente desde el servidor a Meta. Así pierdes menos datos por restricciones del navegador, cookies bloqueadas o bloqueadores de anuncios, y mejoras la atribución y los informes de tus campañas. Para conectarla necesitas un **token de acceso**, y en esta guía te explicamos cómo generarlo.

## Qué es la API de conversiones de Meta

La API de conversiones de Meta (Conversions API) permite enviar eventos directamente desde tu servidor a Meta, en lugar de depender únicamente del seguimiento basado en el navegador.

A diferencia del seguimiento exclusivo del navegador, la API de conversiones hace que tus eventos sean más confiables porque reduce el impacto de:

- Restricciones de privacidad del navegador
- Limitaciones de cookies
- Bloqueadores de anuncios
- Interrupciones de la red
- Tecnologías de prevención del seguimiento

Cuando se utiliza junto con el seguimiento del navegador, la API de conversiones proporciona una visión más completa de la actividad del cliente y del rendimiento de las conversiones.

## Por qué usar la API de conversiones

El uso combinado de eventos del navegador y eventos del servidor te da una medición más sólida y confiable.

### Beneficios clave

| Beneficio | Detalle |
| :-- | :-- |
| **Mayor precisión en la detección de eventos** | Permite capturar eventos que, de otro modo, podrían estar bloqueados por las restricciones del navegador. |
| **Mejor atribución** | Proporciona a Meta datos de conversión más completos para la elaboración de informes y la optimización. |
| **Reducción de la pérdida de datos** | Continúa realizando un seguimiento de los eventos importantes incluso cuando el seguimiento del navegador esté limitado. |
| **Optimización mejorada de la campaña** | Proporciona a Meta señales más confiables para mejorar la entrega y el rendimiento de los anuncios. |
| **Medición preparada para el futuro** | Mantiene el seguimiento de eventos a medida que evolucionan los requisitos de privacidad y las restricciones de los navegadores. |

## Dónde está la configuración en Meta

Meta actualizó la interfaz del Administrador de eventos y cambió de lugar la configuración de los píxeles.

### Ruta de navegación actual

Entra a:

**Administrador de eventos → Orígenes de datos → selecciona tu píxel → Configuración → API de conversiones**

Si gestionas varios píxeles, primero selecciona el correcto en **Orígenes de datos** antes de abrir **Configuración**.

### Interfaz anterior y actual

| Interfaz anterior | Interfaz actual |
| :-- | :-- |
| Administrador de eventos | Administrador de eventos |
| Seleccionar píxel | Orígenes de datos → Seleccionar píxel |
| Configuración | Configuración |
| API del lado del servidor para web | API de conversiones |

## Cómo generar un token de acceso a la API de conversiones

El token de acceso es la clave que permite que Chateea envíe de forma segura eventos del servidor a Meta.

<Steps>
  <Step title="Abre el Administrador de eventos">
    - Inicia sesión en tu cuenta de Meta y abre el Administrador de eventos.
    - Ve a **Orígenes de datos** y selecciona el píxel que quieres configurar.
  </Step>
  <Step title="Abre la configuración del píxel">
    Después de seleccionar el píxel:

    - Abre la pestaña **Configuración**.
    - Desplázate hasta la sección **API de conversiones**.

    En versiones anteriores de Meta, esta sección puede aparecer como **API del lado del servidor para la web**.
  </Step>
  <Step title="Genera el token de acceso">
    Dentro de la sección **API de conversiones**:

    - Haz clic en **Generar token de acceso** (Generate Access Token o Create Access Token).
    - Completa las solicitudes de autorización que aparezcan.
    - Selecciona la aplicación adecuada si se te solicita.
    - Genera el token.
    - Copia el token para usarlo en Chateea.
  </Step>
  <Step title="Guarda el token de forma segura">
    - Guárdalo en un lugar seguro y úsalo al configurar la API de conversiones en Chateea.
    - Trátalo como una contraseña: quien lo tenga puede enviar eventos a tu píxel.
  </Step>
</Steps>

## Variaciones de la interfaz de Meta

Según la configuración de tu cuenta de Meta, puedes ver pantallas distintas durante el proceso. Es posible que te pida:

- Seleccionar un píxel
- Seleccionar una aplicación
- Crear una aplicación
- Asignar permisos
- Verificar el acceso del negocio

Estas variaciones son normales y dependen de los permisos de tu cuenta y de la configuración de tu negocio.

Una vez completado el proceso, el token de acceso generado funciona igual, sin importar qué variación de la interfaz veas.

## Solución de problemas

Si no encuentras la sección de la API de conversiones o no puedes generar un token de acceso, revisa los siguientes puntos.

<AccordionGroup>
  <Accordion title="Verifica el acceso al píxel">
    Confirma que:

    - Iniciaste sesión en la cuenta de Meta correcta.
    - El píxel pertenece a la cuenta de Business Manager que estás administrando.
    - Tienes permisos de administrador sobre el píxel.
  </Accordion>

  <Accordion title="Actualiza el Administrador de eventos">
    Si hubo cambios recientes de permisos:

    - Actualiza la página.
    - Cierra sesión y vuelve a entrar.
    - Vuelve a abrir el Administrador de eventos.
  </Accordion>

  <Accordion title="Revisa el origen de datos seleccionado">
    Cuando administras varios píxeles, es fácil seleccionar el equivocado. Confirma que elegiste el píxel correcto antes de abrir **Configuración**.
  </Accordion>

  <Accordion title="Verifica los permisos del negocio">
    Si falta la sección de la API de conversiones:

    - Verifica el acceso de administrador.
    - Confirma que se hayan completado los requisitos de verificación del negocio, si corresponde.
  </Accordion>
</AccordionGroup>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Por qué mis pantallas se ven diferentes a lo que describe esta guía?">
    Meta actualiza periódicamente la interfaz del Administrador de eventos. La ubicación de la configuración puede cambiar, pero la sección de la API de conversiones sigue estando disponible desde el área de Configuración del píxel.
  </Accordion>

  <Accordion title="¿La API del lado del servidor para web es lo mismo que la API de conversiones?">
    Sí. Meta renombró partes de la interfaz, pero la función cumple el mismo propósito de enviar eventos del lado del servidor.
  </Accordion>

  <Accordion title="¿Por qué no puedo generar un token de acceso?">
    La mayoría de los problemas con el token de acceso se deben a permisos insuficientes sobre el píxel o sobre la cuenta de Business Manager.
  </Accordion>

  <Accordion title="¿Necesito el seguimiento del navegador y la API de conversiones a la vez?">
    Usar ambos en conjunto proporciona el seguimiento de eventos y la atribución más completos.
  </Accordion>

  <Accordion title="¿Puedo volver a generar un token de acceso más adelante?">
    Sí. Puedes generar tokens nuevos desde la sección de la API de conversiones siempre que sea necesario.
  </Accordion>

  <Accordion title="¿Qué pasa si mi token queda comprometido?">
    Genera un token nuevo de inmediato y actualízalo en la configuración de Chateea donde lo usabas.
  </Accordion>
</AccordionGroup>

## ¿Necesitas ayuda?

Si tienes problemas para encontrar la configuración del píxel o generar el token, confirma primero que:

- Iniciaste sesión en la cuenta de Meta correcta.
- Tienes acceso de administrador al píxel.
- Seleccionaste el origen de datos (píxel) correcto.
- El token se generó y se copió completo.
- Los cambios recientes de permisos ya se aplicaron.

Si no llegan eventos después de la configuración, revisa que el token esté bien pegado en Chateea y que el envío de eventos del servidor esté activo.

Si el problema continúa, escribe a soporte de Chateea en **help@chateea.com** o por WhatsApp al **+1 829-580-7071**. Para ayudarte más rápido, incluye capturas de la configuración del píxel y de cualquier mensaje de error, los pasos que ya hiciste y si los eventos no se envían, no aparecen en los informes o no llegan a Meta.
