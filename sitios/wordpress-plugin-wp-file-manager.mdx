WP File Manager es un plugin gratuito que te deja ver, subir, editar y borrar los archivos de tu sitio directamente desde el administrador de WordPress. No necesitas instalar un programa ni configurar credenciales: entras a WordPress y ahí tienes todos tus archivos en una interfaz clara, con un árbol de carpetas y una vista de contenido.

Es una alternativa estable y práctica al acceso por FTP, útil para tareas rápidas como editar el archivo `.htaccess` o subir un archivo puntual.

## Por qué usarlo en lugar de FTP

El FTP tradicional no es seguro: los datos, el usuario y la contraseña viajan en texto plano, y alguien podría interceptarlos con poco esfuerzo. WP File Manager trabaja dentro de tu sesión de WordPress, por lo que no expones credenciales adicionales.

- La versión gratuita cubre la gestión básica de archivos.
- La licencia de pago agrega funciones avanzadas, como crear carpetas privadas o controlar qué operaciones puede hacer cada rol de usuario. Es útil si varias personas de tu equipo administran el sitio.

<Info>
  Si prefieres trabajar con un programa en tu computadora, usa [SFTP](/sitios/wordpress-acceso-sftp), que sí es un canal cifrado.
</Info>

## Instalar WP File Manager

<Steps>
  <Step title="Entra al administrador de WordPress">
    Abre tu sitio en **Sitios → WordPress** y haz clic en **WP Admin**.
  </Step>
  <Step title="Ve a Plugins">
    En el menú de WordPress, haz clic en **Plugins → Añadir nuevo**.
  </Step>
  <Step title="Busca el plugin">
    Escribe "WP File Manager" en el buscador y ubica el plugin oficial.
  </Step>
  <Step title="Instala y activa">
    Haz clic en **Instalar ahora** y luego en **Activar**. El administrador de archivos aparecerá en el menú lateral de WordPress.
  </Step>
</Steps>

Puedes leer más sobre el plugin en su [página oficial de WordPress.org](https://wordpress.org/plugins/wp-file-manager/).

<Warning>
  Igual que con FTP, si modificas o borras el archivo equivocado puedes romper el sitio. Crea una copia de seguridad antes de hacer cambios y, si algo falla, restaura el sitio desde la copia estable más reciente.
</Warning>
