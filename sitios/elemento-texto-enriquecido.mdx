El elemento **Texto enriquecido** (Rich Text) es un bloque de texto con controles tipo procesador de palabras dentro del editor de embudos y sitios web. En un solo elemento puedes combinar párrafos y titulares, citas, código, listas de varios niveles y resaltados de color, sin bloques HTML ni herramientas externas.

## Ventajas

- **Formato sencillo**: cambia entre párrafo y titulares en segundos.
- **Listas avanzadas**: viñetas (disco, círculo, cuadrado) y numeración (números, letras y romanos), con niveles anidados.
- **Resaltados y citas**: destaca frases clave con color de fondo o bloques de cita.
- **Atajos tipo Markdown**: escribe `>` o tres comillas invertidas para crear citas y bloques de código.
- **Sin código**: no necesitas HTML ni CSS.
- **Sin curva de aprendizaje**: la barra lateral es la misma del elemento Párrafo.

## Cómo agregar un texto enriquecido

<Steps>
  <Step title="Abre el editor">
    Abre la página de tu embudo o sitio web en el editor.
  </Step>
  <Step title="Agrega el elemento">
    En el panel izquierdo, haz clic en **Agregado rápido** (Quick Add) y elige **Texto enriquecido** (Rich Text).
  </Step>
  <Step title="Empieza a escribir">
    Arrastra el elemento a una fila o columna y haz clic en él para empezar a editar.
  </Step>
</Steps>

## Funciones de formato

### Cambiar entre párrafo y titulares

1. Selecciona el texto.
2. En la barra flotante, abre el menú **Párrafo**.
3. Elige el nivel de titular (H1 a H6).

### Citas

1. Escribe el símbolo `>` al inicio de una línea.
2. Pulsa **Enter** (o espacio) para crear el bloque de cita.
3. Escribe tu texto. Es ideal para testimonios o frases destacadas.

### Código en línea

Rodea el texto con comillas invertidas simples, por ejemplo `codigo`, para mostrarlo con formato de código dentro de una frase.

### Bloques de código

1. Escribe tres comillas invertidas seguidas.
2. Pulsa **Enter** para crear el bloque.
3. Escribe o pega el código.

### Listas avanzadas y anidadas

1. Crea la lista escribiendo un asterisco (`*`) seguido de un espacio, o selecciona el texto y haz clic en **Lista con viñetas** o **Lista numerada** en la barra flotante.
2. Abre el menú junto a la viñeta para elegir el tipo:
   - **Con viñetas**: disco, círculo o cuadrado.
   - **Numeradas**: 1 2 3, a b c, A B C, i ii iii o I II III.
3. Pulsa **Tab** para crear un subnivel y **Mayús + Tab** para volver al nivel anterior.

### Resaltar texto con color de fondo

Selecciona el texto, haz clic en el ícono del selector de color de la barra flotante y elige el color de resaltado.

## Atajos de teclado y Markdown

| Acción | Atajo |
| --- | --- |
| Cambiar párrafo a titular | Ctrl + Alt + 1 a 6 (Windows) o Cmd + Option + 1 a 6 (Mac) |
| Cita | Escribe `>` y espacio al inicio de la línea |
| Código en línea | Rodea el texto con comillas invertidas |
| Bloque de código | Escribe tres comillas invertidas y pulsa Enter |
| Color de resaltado | Selecciona el texto y elige un color |

## Opciones de estilo de la barra lateral

Todo lo que ajustas en un elemento Párrafo también funciona aquí:

- **Tipografía**: familia, peso, tamaño e interlineado.
- **Espaciado**: márgenes y relleno para escritorio, tableta y celular.
- **Efectos**: sombras y animaciones de entrada.
- **Visibilidad**: mostrar u ocultar el elemento según el dispositivo.
- **Avanzado**: clase CSS personalizada.

### Espacio entre elementos de lista

La opción **Espacio entre elementos de lista** (List Item Spacing) controla la separación vertical entre cada elemento de una lista, sin cambiar el interlineado del texto. Mejora la lectura de listas largas y da aire en pantallas pequeñas.

1. Selecciona un elemento de texto enriquecido o de lista de viñetas.
2. En el panel de estilo, busca **Espacio entre elementos de lista**, junto a **Interlineado**.
3. Mueve el control deslizante o escribe un valor.

<Tip>
Usa el interlineado para el espacio entre líneas dentro de un mismo punto, y el espacio entre elementos de lista para separar un punto del siguiente.
</Tip>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Puedo convertir un elemento Párrafo en Texto enriquecido?">
    No. Para cambiar entre titular y párrafo, el texto debe estar en un elemento de texto enriquecido.
  </Accordion>
  <Accordion title="¿Cómo creo listas anidadas?">
    Después de crear el primer punto, pulsa **Tab** o usa la opción de sangría para crear subniveles.
  </Accordion>
  <Accordion title="¿Puedo usar Texto enriquecido y Párrafo indistintamente?">
    Sí, pero el texto enriquecido tiene herramientas de formato que el párrafo no tiene.
  </Accordion>
  <Accordion title="¿Se aplican mis fuentes y colores globales?">
    Sí. El elemento hereda la configuración global de tu tema.
  </Accordion>
</AccordionGroup>
