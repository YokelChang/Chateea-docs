# ERROR: 30032

## Descripción

Usted envió un mensaje (SID del mensaje: `SMXXXXX`) desde un número gratuito a un usuario de telefonía móvil en EE. UU. o Canadá. Lead Connector requiere que todos los números gratuitos pasen por un proceso de verificación. El número gratuito desde el que envió el mensaje no ha sido verificado mediante el proceso de verificación requerido.

## Posibles causas

- \*Su número gratuito no ha sido verificado para permitir el envío de tráfico en EE. UU. y Canadá.
- \*Su solicitud de verificación gratuita fue rechazada.

## Posibles soluciones

Consulte este [artículo de soporte](https://help.leadconnectorhq.com/en/support/solutions/articles/155000000180) para conocer el proceso de verificación de su número gratuito.

<Warning>
  A partir del **8 de noviembre de 2023**, se bloquearán los mensajes enviados a números de teléfono gratuitos **restringidos**. A partir del **31 de enero de 2024**, se bloquearán los mensajes enviados a números de teléfono gratuitos **pendientes**.
</Warning>
