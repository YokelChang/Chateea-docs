# ERROR: 21635

## Descripción

Has intentado enviar un SMS con un número **de teléfono** fijo como destinatario.

## Posibles causas

El número **que** proporcionaste es un número de teléfono fijo.

## Posibles soluciones

- Contacta con soporte.
