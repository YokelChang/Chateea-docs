# ERROR: 30006

Referencia del proveedor: [https://www.twilio.com/docs/api/errors/30006#error-30006](https://www.twilio.com/docs/api/errors/30006#error-30006)

## Descripción

**Entrega de mensajes: teléfono fijo o operador inaccesible.**

El número de destino no puede recibir este mensaje.

## Posibles causas

- El número de destino no puede recibir este mensaje. Entre las posibles razones se incluyen el intento de comunicarse con un teléfono fijo o, en el caso de códigos cortos, una operadora inaccesible.
- Su mensaje fue enviado a un teléfono fijo o a un operador que no está disponible para este tipo de número de teléfono.
