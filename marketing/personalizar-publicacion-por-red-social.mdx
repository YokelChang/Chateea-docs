Cada red social tiene su propio público, su límite de caracteres y sus formatos de imagen y video. Con la opción **Personalizar para cada red** puedes escribir, dentro de una misma publicación del Planificador social, un texto y unos archivos distintos para cada red, y programarlo todo de una sola vez.

## Para qué sirve

- **Respetar los límites de cada red:** un texto largo para Facebook y uno breve para el Perfil de empresa de Google, en la misma publicación.
- **Adaptar el tono:** más profesional en LinkedIn, más cercano en Instagram.
- **Usar el formato correcto:** imágenes o videos distintos según lo que admite cada red.
- **Ahorrar tiempo:** no necesitas crear una publicación separada por red.

## Cómo personalizar una publicación

<Steps>
  <Step title="Crea una publicación">
    Ve a **Marketing → Planificador social** y haz clic en **Crear nueva publicación**.
  </Step>
  <Step title="Selecciona varias redes">
    Elige dos o más cuentas, por ejemplo Facebook, Instagram, LinkedIn y Perfil de empresa de Google. La opción de personalizar solo aparece cuando hay más de una red seleccionada.
  </Step>
  <Step title="Activa la personalización">
    Activa el interruptor **Personalizar para cada red**. Verás una pestaña o sección para cada red.
  </Step>
  <Step title="Escribe el contenido de cada red">
    Redacta el texto de cada red respetando su límite de caracteres. Si lo necesitas, usa la IA de contenido para generar o adaptar el texto a una longitud corta, media o larga según la red.
  </Step>
  <Step title="Agrega imágenes o videos">
    Sube los archivos adecuados para cada red.
  </Step>
  <Step title="Publica o programa">
    Revisa el contenido de todas las redes y publica ahora o programa la publicación.
  </Step>
</Steps>

## Límites de caracteres

| Red | Límite de caracteres |
| --- | --- |
| Páginas y grupos de Facebook | 5.000 |
| Perfiles de Instagram | 2.200 |
| Páginas y perfiles de LinkedIn | 3.000 |
| Perfil de empresa de Google | 1.500 |

Si el texto supera el límite de una red, el editor te avisa y tendrás que acortarlo antes de publicar.

## Tenlo en cuenta

<Warning>
  Si desactivas **Personalizar para cada red**, el contenido de la red que tengas abierta se aplicará a todas las redes seleccionadas y perderás el contenido personalizado de las demás. El sistema te mostrará una advertencia antes.
</Warning>

- Si un archivo todavía se está subiendo, cambiar las cuentas seleccionadas o el interruptor de personalización puede cancelar la carga.
- Si la miniatura de un video se está procesando, cambiar de cuenta o el interruptor puede interrumpir el proceso y tendrás que volver a aplicar la miniatura.
- Espera a que terminen las cargas antes de hacer cambios en la selección de redes.

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Qué pasa si mi texto supera el límite de una red?">
    Tendrás que editarlo para que quepa en esa red. El editor indica cuándo te pasas del número de caracteres permitido.
  </Accordion>
  <Accordion title="¿Puedo personalizar publicaciones recurrentes?">
    Sí. Al crear una publicación recurrente también puedes activar la personalización para adaptar el contenido de cada red.
  </Accordion>
</AccordionGroup>
