Con la importación por CSV puedes subir de una sola vez muchos registros de pago, por ejemplo cobros que hiciste fuera de Chateea o el historial de otro sistema. Si preparas el archivo con el formato correcto, los datos se procesan bien y evitas los errores de importación más comunes.

## Requisitos de formato CSV

| Requisito | Detalle |
| --- | --- |
| **Extensión** | El archivo debe guardarse en formato `.csv` |
| **Encabezados** | Deben coincidir **exactamente** con los nombres de columna de la tabla de abajo (en inglés, tal como aparecen) |
| **Filas** | Cada fila representa una transacción |
| **Datos obligatorios** | Todos los campos obligatorios deben tener datos válidos |
| **Limpieza** | Evita espacios de más, símbolos o formatos no compatibles |

## Campos de la transacción

Cada columna representa un dato de la transacción. Esta es la estructura completa, con su descripción y un ejemplo. Los encabezados van en inglés, escritos exactamente así:

| Columna | Descripción | Ejemplo |
| --- | --- | --- |
| **Customer First Name** | Nombre del cliente | John |
| **Customer Last Name** | Apellido del cliente | Doe |
| **Customer Email** | Correo del cliente | [john.doe@example.com](mailto:john.doe@example.com) |
| **Customer Phone** | Teléfono (incluye código de país si lo tienes) | \+14155552671 |
| **Currency** | Código ISO de la moneda | USD |
| **Late Fees** | Cargo adicional por pago tardío, si aplica | 2.00 |
| **Tip Amount** | Propina incluida en la transacción | 5.00 |
| **Amount Paid** | Importe final pagado (puede ser Subtotal − Descuento \+ Impuesto \+ Propina \+ Cargos) | 105.00 |
| **Transaction Date** | Fecha en formato `DD/MM/YYYY` | 25/01/2025 |
| **Transaction Time** | Hora en formato `HH:MM` (12 horas) | 12:30 PM |
| **Payment Method** | Método usado: `Credit Card`, `PayPal`, `Cash` o `ACH` | Credit Card |
| **Payment Provider** | Pasarela o proveedor que procesó el pago | Stripe |
| **Address Line 1** | Línea 1 de la dirección del comprador | 4034 Granville Lane |
| **City** | Ciudad | Secaucus |
| **State** | Estado o provincia | New Jersey |
| **Country** | País (ISO de 2 letras o nombre completo) | United States |
| **Postal Code** | Código postal | 07094 |

<Note>
  También puedes incluir campos opcionales como impuestos, descuentos, propinas y detalles de los artículos para que cada transacción quede más completa.
</Note>

## Errores comunes al subir

- Nombres de columna incorrectos
- Campos obligatorios vacíos
- Formatos de fecha no válidos
- Símbolos o espacios de más

<Tip>
  El error más frecuente es un encabezado que no coincide **exactamente**. Antes de subir, compara tus encabezados con la primera columna de la tabla de arriba, letra por letra.
</Tip>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿En qué formato deben estar las fechas?">
    Usa el formato `DD/MM/AAAA` (por ejemplo, 25/01/2025) y mantenlo igual en todas las filas.
  </Accordion>

  <Accordion title="¿Puedo actualizar transacciones existentes con CSV?">
    No. La importación crea registros nuevos. Para evitar duplicados, no vuelvas a subir transacciones que ya importaste.
  </Accordion>
</AccordionGroup>

## Si no puedes cargar el archivo

Compara tu archivo con la estructura de la tabla de arriba. Si aun así no se carga, escribe a soporte de Chateea en **help@chateea.com** o por WhatsApp al **+1 829-580-7071** y adjunta el archivo o una muestra de sus primeras filas.
