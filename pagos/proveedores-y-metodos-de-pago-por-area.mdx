Esta guía rápida te dice qué proveedores y métodos de pago funcionan en cada parte de Chateea: Stripe (con sus billeteras, pagos a plazos y débitos bancarios), PayPal, Square, NMI, Authorize.net, Razorpay y lectores de tarjetas. Úsala para planificar tus checkouts, para elegir proveedor o cuando un método no aparece donde esperabas.

<Note>
Algunos métodos de pago **no admiten suscripciones ni pagos recurrentes**: solo sirven para pagos únicos. Prueba siempre tu caso recurrente antes de lanzarlo.
</Note>

## Qué significa cada área

| Área | Qué incluye |
| --- | --- |
| **Formularios de pedido** | Formularios de embudos y sitios web pensados para vender productos y ofertas |
| **Formularios** | Formularios estándar con el elemento de pago, para cobros o donaciones |
| **Encuestas** | Encuestas con el elemento de pago para cobrar al enviarlas |
| **Checkout desde correo** | Pago que inicia directamente desde un correo, usando un enlace de pago |
| **Tienda** | Tu tienda en línea y su checkout |
| **Facturas** | Facturas únicas y su cobro |
| **Facturas recurrentes** | Plantillas de facturas recurrentes y ciclos de cobro automáticos |
| **Enlaces de pago** | Enlaces a un checkout alojado con uno o varios productos |
| **Cursos** | Pagos por la compra o el acceso a cursos |
| **Comunidades** | Pagos por membresías o grupos de comunidades |
| **Ficha del contacto** | Cobro a una tarjeta guardada o nueva directamente desde el contacto |
| **Calendarios y servicios** | Cobros al reservar citas o servicios |
| **Menú de servicios** | Experiencias de reserva desde un menú de servicios |
| **POS** | Cobros presenciales desde la app móvil o con lectores compatibles |

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="La tabla dice Sí para Apple Pay o Google Pay, pero el botón no aparece. ¿Por qué?">
    Las billeteras solo aparecen en entornos compatibles: Apple Pay en dispositivos Apple (iPhone, iPad o Mac) y Google Pay en dispositivos y navegadores compatibles. Además, el método debe estar activado con tu proveedor y la billetera configurada en el dispositivo del cliente.
  </Accordion>
  <Accordion title="Si un proveedor tiene Sí, ¿las suscripciones funcionarán?">
    No necesariamente. Algunos métodos solo admiten pagos únicos. Prueba tu caso recurrente antes de lanzarlo.
  </Accordion>
  <Accordion title="¿Puedo mostrar Stripe y PayPal en el mismo checkout?">
    En muchas áreas sí, si ambos están conectados y habilitados. El checkout muestra automáticamente las opciones disponibles.
  </Accordion>
  <Accordion title="¿Puedo usar un lector de tarjetas en formularios de pedido o facturas?">
    No. Los lectores de tarjetas solo funcionan en el POS. Usa el POS para los cobros presenciales.
  </Accordion>
</AccordionGroup>
