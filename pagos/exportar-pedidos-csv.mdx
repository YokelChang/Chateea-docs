La exportación de pedidos te permite descargar el detalle de tus pedidos en un archivo CSV para reportes, conciliación, análisis financiero, logística o para medir qué productos se venden más. Puedes exportar todos los pedidos o solo los que coinciden con tus filtros.

## Cómo exportar pedidos

<Steps>
  <Step title="Abre Pedidos">
    Ve a **Pagos → Pedidos**.
  </Step>
  <Step title="Filtra si lo necesitas">
    Puedes filtrar por estado del pedido, rango de fechas, tipo de origen (embudo, enlace de pago, checkout de la tienda, etc.) o tipo de producto (único o recurrente).
  </Step>
  <Step title="Descarga">
    Haz clic en **Descargar**.
  </Step>
  <Step title="Revisa tu correo">
    Recibirás un enlace seguro para descargar el archivo.
  </Step>
</Steps>

<Note>
  El enlace de descarga vence a los **7 días**. Si venció, simplemente genera una exportación nueva.
</Note>

## Cómo está organizado el CSV

Un pedido puede tener varios productos y varios impuestos, así que **un mismo pedido puede ocupar varias filas**. Esto permite ver precios e impuestos por producto, algo necesario para la contabilidad y el análisis.

### Ceros y celdas vacías

| Valor | Cuándo aparece |
| --- | --- |
| **0** | El campo aplica y su valor es realmente cero |
| **Vacío** | El campo no aplica, por ejemplo el método de pago de un pedido sin pagar |

El orden de las columnas es siempre el mismo, así que puedes usar el archivo en tablas dinámicas, importaciones o herramientas de inteligencia de negocio.

<Warning>
  Para sumar totales, agrupa primero por `Internal order id`. Si sumas la columna directamente, contarás varias veces los pedidos que ocupan más de una fila.
</Warning>

## Ejemplos de pedidos en varias filas

**Ejemplo 1.** Un pedido con 3 productos y 2 impuestos no incluidos en el precio, aplicados a los tres productos: cada producto ocupa una fila por impuesto, así que el pedido ocupa **6 filas**, todas con el mismo `Internal order id`.

**Ejemplo 2.** Un pedido con 3 productos donde el producto 1 tiene 2 impuestos no incluidos, el producto 2 tiene 2 impuestos incluidos en el precio y el producto 3 no tiene impuestos:

| Filas | Contenido |
| --- | --- |
| 2 filas | Producto 1 con `Tax Name 1` y `Tax Name 2` |
| 2 filas | Producto 2 con `Tax Name 1 (Included in prices)` y `Tax Name 2 (Included in prices)` |
| 1 fila | Producto 3, sin valores en las columnas de impuestos |

En total, **5 filas** con el mismo `Internal order id`.

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Por qué veo varias filas para el mismo pedido?">
    Porque cada producto y cada impuesto de producto necesita su propia línea contable para que el reporte sea preciso.
  </Accordion>
  <Accordion title="¿Por qué el método de pago está vacío en algunos pedidos?">
    Solo se muestra cuando hubo una transacción. Los pedidos sin pagar no tienen método de pago.
  </Accordion>
  <Accordion title="¿Se incluyen los pedidos sin pagar o abandonados?">
    Sí, salvo que los excluyas con los filtros.
  </Accordion>
  <Accordion title="¿Puedo ver el historial de cobros de las suscripciones?">
    No en esta exportación: solo indica cuántos productos recurrentes tiene cada pedido. Para el detalle de suscripciones usa la exportación de suscripciones, y para el historial de cobros la de transacciones.
  </Accordion>
  <Accordion title="¿Puedo exportar de nuevo pedidos antiguos?">
    Sí. Cada exportación se genera en el momento con los datos actuales.
  </Accordion>
  <Accordion title="¿Quién puede descargar exportaciones de pedidos?">
    Los usuarios con permiso para ver pedidos y exportar pedidos.
  </Accordion>
</AccordionGroup>
