## ¿Qué es el plugin LeadConnector?

El plugin **LeadConnector** para WordPress es una potente herramienta de conversión que permite a tu sitio web captar, interactuar y convertir visitantes con un mínimo esfuerzo. Integra a la perfección widgets de alta conversión como **chats**, **formularios**, **embudos de venta**, **bases de datos telefónicas**, **widgets de reseñas** y **calendarios**, todos diseñados para mejorar tu estrategia de captación de leads directamente desde tu sitio de WordPress.

Tanto si buscas interactuar con tus clientes por SMS o correo electrónico, como si quieres mostrar embudos de venta con un diseño impecable o programar citas con facilidad, LeadConnector es tu kit de herramientas todo en uno para el crecimiento digital, **sin necesidad de escribir una sola línea de código**.

<Tip>
  Este es el nombre exacto con el que aparece el plugin dentro de WordPress: búscalo como **LeadConnector** en el repositorio de plugins, o súbelo como archivo `.zip`. Una vez activado, se conecta a tu cuenta de Chateea y todos los widgets salen de ahí.
</Tip>

  📸 _Espacio para captura: pantalla de bienvenida del plugin dentro del escritorio de WordPress, con el botón "Iniciar sesión en tu cuenta"._
</Note>

### Cómo se organiza dentro de WordPress

Una vez conectado, el plugin agrega su propio menú al escritorio de WordPress, con estas pestañas:

| Pestaña | Para qué sirve |
| :-- | :-- |
| **Dashboard** | Vista general: optimiza la interacción con clientes y centraliza tus esfuerzos de marketing |
| **Funnels** | Publica páginas de embudo de alta conversión dentro de tu sitio |
| **Forms** | Administra todos los formularios integrados desde tu cuenta de CRM |
| **Email** | Gestiona las comunicaciones por correo conectando el servicio SMTP |
| **Phone Numbers** | Rastrea y atribuye llamadas para medir la efectividad de tus campañas |
| **Chat Widget** | Coloca y guarda widgets de chat en tu sitio web |

<Tip>
  En la esquina superior derecha del panel verás el indicador de **conexión con tu cuenta**. Si aparece desconectado, ninguno de los widgets se mostrará en el sitio público: revisa ese estado antes de diagnosticar cualquier otro problema.
</Tip>

## Características y capacidades clave

### Widget de texto a chat

Integra un **widget de chat en tiempo real** directamente en tu sitio web. Este chat puede configurarse para **iniciar conversaciones automáticamente mediante SMS**, guiando a los visitantes desde el interés inicial hasta la conversión de forma rápida y natural.

| Función clave | Qué permite |
| :-- | :-- |
| Personalización | Ajustar mensajes de bienvenida, colores y marca del chat |
| Gestión de mensajes | Ver y responder las conversaciones sin salir del flujo de trabajo |

<Note>
  📸 _Espacio para captura: pestaña "Chat Widget" con el interruptor de activación y el panel de funciones clave._
</Note>

### Páginas de embudo incrustadas

Integra páginas de embudo de alta efectividad en tu sitio de WordPress con un simple **shortcode o widget**. No necesitas redirecciones ni pestañas externas: los visitantes se mantienen inmersos en tu sitio.

El listado de páginas de embudo muestra:

| Columna | Qué informa |
| :-- | :-- |
| **Page** | La ruta de WordPress donde quedó incrustado el embudo |
| **Funnel Name** | El embudo de origen dentro de tu cuenta |
| **Status** | Si la página está publicada (_Live_) o no |
| **Last Updated** | Fecha del último cambio |
| **Step** | El paso específico del embudo que se está mostrando |
| **Actions** | Ver, editar o eliminar la página incrustada |

<Tip>
  Mantener al visitante dentro de tu dominio en lugar de enviarlo a una URL externa mejora la percepción de marca y evita que se pierda la atribución de la visita.
</Tip>

### Integración de formularios

Integra formularios que capturen directamente la información del usuario —**correo electrónico, teléfono, nombre**— y sincronízalos **al instante** con tu CRM o con tus flujos de trabajo de marketing.

El listado de formularios muestra:

| Columna | Qué informa |
| :-- | :-- |
| **Name** | Nombre del formulario |
| **Status** | Si está activo |
| **Created At** | Fecha de creación |
| **Last Updated** | Fecha de la última modificación |
| **Submissions** | Cantidad de envíos recibidos |

<Note>
  📸 _Espacio para captura: pestaña "Forms" con el listado de formularios y sus envíos._
</Note>

### Sistemas de seguimiento por correo electrónico y teléfono

Optimiza la atribución y el seguimiento mediante el **rastreo dinámico de correos electrónicos y números de teléfono**. Cada formulario o envío de embudo se vincula a su origen, para una mejor medición del rendimiento de la campaña.

**Servicio SMTP de correo.** Desde la pestaña **Email** seleccionas el dominio y el nombre de usuario desde los que saldrán tus envíos, y guardas la configuración.

| Función clave | Qué permite |
| :-- | :-- |
| Integración SMTP | Entrega de correo sin fricción usando tu propia configuración |
| Campañas | Crear y administrar campañas de correo electrónico |
| Métricas | Registrar aperturas, clics y otras métricas de interacción |

<Warning>
  Si tienes activo otro plugin de SMTP en WordPress (por ejemplo, **WP Mail SMTP**), el sistema te avisará de un posible conflicto. Se recomienda **desactivar el plugin de terceros** para que la entrega de correos funcione de forma consistente.
</Warning>

**Grupo de seguimiento de números telefónicos.** La pestaña **Phone Numbers** rastrea y atribuye llamadas con esta información:

| Columna | Qué informa |
| :-- | :-- |
| **Pool Friendly Name** | Nombre interno del grupo de números |
| **Visitor Source** | Origen del visitante al que se le asigna el número |
| **Tracking Number** | Cantidad de números de seguimiento del grupo |
| **Forwarding Number** | Número al que se desvía finalmente la llamada |
| **Status** | Si el grupo está activo |

<Note>
  📸 _Espacio para captura: pestañas "Email" y "Phone Numbers" con la configuración SMTP y el grupo de seguimiento._
</Note>

## Cómo empezar

<Steps>
  <Step title="Instala el plugin LeadConnector">
    Instálalo desde tu panel de WordPress o sube el archivo `.zip`.
  </Step>
  <Step title="Actívalo y conecta tu cuenta">
    Tras la activación, inicia sesión para vincular tu cuenta y habilitar los widgets.
  </Step>
  <Step title="Personaliza los widgets">
    Elige los que necesites: chat, calendario, formulario, embudo, etc.

  <Step title="Pega los enlaces de inserción o códigos cortos">
    Colócalos en cualquier página o entrada de tu sitio.

  <Step title="Lanza">

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Necesito saber programar para usarlo?">
    No. Todo se inserta arrastrando y soltando o pegando un código corto que el propio plugin genera.
  </Accordion>

  <Accordion title="¿Afecta la velocidad de mi sitio?">
    El plugin está diseñado para tener un impacto mínimo en el rendimiento. Además, al reemplazar varios scripts de terceros por una sola integración, en muchos casos el sitio termina cargando menos recursos que antes.
  </Accordion>

  <Accordion title="Instalé el plugin pero los widgets no aparecen en el sitio">
    Revisa que la cuenta esté conectada (indicador en la esquina superior derecha del panel del plugin), que el widget esté activado con su interruptor, y que el código corto esté pegado en una página publicada y no en un borrador.
  </Accordion>

  <Accordion title="¿Puedo usarlo si administro varios sitios de clientes?">
    Sí. Es escalable tanto para un emprendedor individual como para una agencia que gestiona más de 100 clientes.
  </Accordion>
</AccordionGroup>
