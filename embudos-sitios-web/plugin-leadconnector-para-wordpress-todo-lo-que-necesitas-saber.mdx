El plugin de Chateea para WordPress conecta tu sitio de WordPress con tu cuenta de Chateea. Con él insertas en tus páginas el chat, embudos, formularios, calendarios, widgets de reseñas, encuestas y cuestionarios que ya configuraste en Chateea, sin pegar códigos de inserción a mano ni instalar otros plugins. Todo lo que llega desde el sitio (contactos, citas, respuestas, reseñas) se guarda en tu cuenta, listo para tus automatizaciones y seguimientos.

## Qué puedes hacer con el plugin

| Herramienta | Para qué sirve |
| --- | --- |
| **Widget de chat** | Conversa con tus visitantes en tiempo real y continúa la conversación por SMS |
| **Embudos** | Muestra pasos de tus embudos dentro de páginas de tu propio dominio |
| **Formularios** | Captura nombre, correo y teléfono y envíalos al instante a tu CRM |
| **Calendarios** | Deja que tus clientes reserven citas sin salir de tu sitio |
| **Widgets de reseñas** | Muestra tus mejores reseñas para generar confianza |
| **Encuestas** | Recoge opiniones y datos estructurados de tus clientes |
| **Cuestionarios** | Capta leads con experiencias interactivas y segmenta según el resultado |
| **Valores personalizados** | Muestra datos de tu cuenta que se actualizan solos en el sitio |
| **Correo (SMTP)** | Envía los correos de WordPress desde tu dominio |
| **Números de seguimiento** | Atribuye las llamadas al origen de cada visitante |

Los calendarios, widgets de reseñas, encuestas y cuestionarios están disponibles desde la **versión 3.0.13** del plugin. Los valores personalizados requieren la **versión 3.5.0** o superior.

## Instalar y conectar el plugin

Si tu sitio de WordPress está alojado en Chateea, el plugin viene instalado de fábrica. Puedes revisar su estado en **Sitios → WordPress**, con **Administrar sitio web** (Manage Website) y la pestaña **Plugins**.

Si tu WordPress está alojado en otro proveedor:

<Steps>
  <Step title="Sube el plugin">
    En el escritorio de WordPress, ve a **Plugins → Añadir nuevo → Subir plugin**, selecciona el archivo `.zip` del plugin y haz clic en **Instalar ahora**. Si no tienes el archivo, pídelo a soporte de Chateea en **help@chateea.com**.
  </Step>
  <Step title="Actívalo">
    Cuando termine la instalación, haz clic en **Activar plugin**.
  </Step>
  <Step title="Conecta tu cuenta">
    Abre el menú del plugin en WordPress, inicia sesión con tu usuario de Chateea y elige tu cuenta. Al terminar, el plugin sincroniza tus datos y confirma la conexión.
  </Step>
  <Step title="Inserta lo que necesites">
    Elige el widget o elemento, copia su código corto (shortcode) o usa su bloque, y colócalo en cualquier página o entrada.
  </Step>
  <Step title="Publica">
    Publica la página y empieza a captar clientes.
  </Step>
</Steps>

<Tip>
  En la parte superior del panel del plugin verás el indicador de conexión con tu cuenta. Si aparece desconectado, ningún widget se mostrará en tu sitio público. Revísalo antes de buscar cualquier otra causa.
</Tip>

## El menú del plugin en WordPress

Una vez conectado, el plugin agrega su propio menú al escritorio de WordPress. Estas son sus secciones principales:

| Sección | Para qué sirve |
| --- | --- |
| **Panel** (Dashboard) | Vista general de la conexión y de tus herramientas |
| **Embudos** (Funnels) | Publica pasos de embudos dentro de tu sitio |
| **Formularios** (Forms) | Consulta los formularios de tu cuenta y sus envíos |
| **Correo** (Email) | Configura el envío de correos de WordPress por SMTP |
| **Números de teléfono** (Phone Numbers) | Gestiona tus grupos de números de seguimiento |
| **Widget de chat** (Chat Widget) | Activa y guarda el chat en tu sitio |
| **Reseñas, Calendarios, Encuestas, Cuestionarios** | Copia el código corto de cada elemento para insertarlo |
| **Valores personalizados** | Consulta y copia tus valores sincronizados |

## Widget de chat

Agrega un chat en tiempo real a tu sitio. Puedes configurarlo para que la conversación continúe por SMS, de modo que el visitante siga en contacto contigo aunque cierre la página. Desde la pestaña del chat ajustas el mensaje de bienvenida, los colores y el estilo, y las conversaciones llegan a **Conversaciones** en Chateea.

## Embudos dentro de tu sitio

Inserta un paso de tus embudos en una página de WordPress con un código corto o un widget. El visitante no sale de tu dominio, lo que mejora la percepción de tu marca y evita que se pierda la atribución de la visita.

El listado de embudos del plugin muestra:

| Columna | Qué informa |
| --- | --- |
| **Página** | La ruta de WordPress donde está insertado el embudo |
| **Nombre del embudo** | El embudo de origen en tu cuenta |
| **Estado** | Si la página está publicada |
| **Última actualización** | Fecha del último cambio |
| **Paso** | El paso del embudo que se muestra |
| **Acciones** | Ver, editar o eliminar la página insertada |

## Formularios

Inserta tus formularios de Chateea para captar correo, teléfono y nombre. Cada envío se sincroniza al instante con tus contactos y puede disparar tus flujos de trabajo. El listado muestra el nombre de cada formulario, su estado, la fecha de creación, la última actualización y el número de envíos.

## Calendarios

Permite que tus clientes reserven directamente en tu sitio, en una página de reservas, en el pie de página o junto a la descripción de cada servicio.

1. Crea o ajusta el calendario en Chateea (disponibilidad, equipo, confirmaciones).
2. En WordPress, abre la sección **Calendarios** del plugin y elige el calendario.
3. Copia su código corto y pégalo donde quieras que se pueda reservar.
4. Publica la página. Las citas llegan a tu cuenta de Chateea.

<Tip>
  Coloca el calendario cerca de tu llamado a la acción y deja poco texto alrededor, para que la atención se centre en reservar. Si ofreces varios servicios, inserta un calendario por servicio con un encabezado claro para cada uno.
</Tip>

## Widgets de reseñas

Muestra la opinión de tus clientes en tu página de inicio, de precios o de servicios para aumentar la confianza y las conversiones.

1. Crea y personaliza el widget de reseñas en Chateea.
2. En WordPress, abre la sección **Reseñas** del plugin y elige el widget.
3. Copia su código corto y colócalo en cualquier sección o columna de tu página.
4. Publica. Las reseñas se muestran con los filtros y estilos que definiste en Chateea.

Un carrusel funciona bien en la página de inicio; en páginas de servicios, una cuadrícula fija es más fácil de leer. Si quieres varios widgets en una misma página, inserta cada uno con su propio código corto.

## Encuestas

Úsalas para medir la satisfacción, recopilar datos de incorporación o calificar leads.

1. Crea la encuesta en Chateea con sus preguntas, lógica y acciones al completar.
2. En WordPress, abre la sección **Encuestas** del plugin y copia el código corto.
3. Pégalo en tu página, revisa cómo se ve en celular y publica.
4. Las respuestas y sus estadísticas quedan en Chateea para tu seguimiento.

Mantén las encuestas cortas y ubícalas en páginas de agradecimiento o dentro de artículos del blog para obtener respuestas en contexto.

## Cuestionarios

Los cuestionarios atraen la atención y captan leads con una experiencia interactiva. Según el resultado, puedes segmentar a cada contacto y lanzar automatizaciones distintas.

1. Crea el cuestionario en Chateea con sus preguntas, puntuación, resultados y páginas de resultado.
2. En WordPress, abre la sección **Cuestionarios** del plugin y copia el código corto.
3. Publica. Cada cuestionario completado se sincroniza con Chateea y puedes usar el resultado en tus flujos de trabajo.

Funcionan mejor en páginas de primer contacto y acompañados de un incentivo claro. Después, usa llamados a la acción distintos según el resultado.

## Correo y números de seguimiento

**Correo por SMTP.** En la sección **Correo** eliges el dominio y el usuario desde los que saldrán los correos de WordPress y guardas la configuración. Así tus correos se envían desde tu propio dominio.

<Warning>
  Si tienes activo otro plugin de SMTP (por ejemplo, WP Mail SMTP), el plugin te avisará del conflicto. Desactiva el plugin de terceros para que los correos se entreguen de forma consistente.
</Warning>

**Números de seguimiento.** La sección **Números de teléfono** muestra tus grupos de números de seguimiento: su nombre, el origen de visitante al que se asignan, la cantidad de números, el número al que se desvían las llamadas y su estado. Así sabes qué campaña genera cada llamada.

## Editores compatibles

Los códigos cortos del plugin funcionan en Gutenberg, el editor clásico, Elementor, Divi y cualquier constructor que acepte códigos cortos de WordPress. En los constructores visuales, usa el elemento o widget de código corto.

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Necesito saber programar?">
    No. Todo se inserta pegando el código corto que genera el plugin o usando sus bloques.
  </Accordion>
  <Accordion title="¿Dónde se guardan las citas, respuestas y reseñas?">
    En tu cuenta de Chateea. WordPress solo muestra el elemento; los datos y las estadísticas quedan en Chateea para tu seguimiento.
  </Accordion>
  <Accordion title="¿Puedo poner varios calendarios o widgets de reseñas en una misma página?">
    Sí. Inserta cada uno con su propio código corto. Mantén un diseño sencillo para que la página cargue rápido.
  </Accordion>
  <Accordion title="¿Funciona con Elementor y Divi?">
    Sí. Usa el elemento de código corto de tu constructor, o los bloques de Gutenberg cuando estén disponibles.
  </Accordion>
  <Accordion title="¿Afecta la velocidad de mi sitio?">
    El plugin está pensado para tener un impacto mínimo. Además, al reemplazar varios scripts y plugins de terceros por una sola integración, muchas veces el sitio termina cargando menos recursos.
  </Accordion>
  <Accordion title="Instalé el plugin pero los widgets no aparecen">
    Comprueba que la cuenta esté conectada en el panel del plugin, que el widget esté activado y que el código corto esté en una página publicada, no en un borrador. Si usas un plugin de caché, vacía la caché.
  </Accordion>
</AccordionGroup>
