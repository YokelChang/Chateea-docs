## ¿Qué es un generador de marcado de esquema?

El Generador de Marcado de Esquema es una herramienta nativa del Creador de Sitios Web y Embudos que te permite crear, validar y publicar marcado de esquema (datos estructurados) para páginas individuales. Los datos estructurados ayudan a los motores de búsqueda y a los sistemas de IA a interpretar detalles clave como el tipo de negocio, los productos, las preguntas frecuentes, los artículos, los eventos y mucho más.

<Warning>
  **Nota:** El esquema es específico de la página y **no se aplica a otras páginas ni a los pasos del embudo**.
</Warning>

## Principales ventajas del generador de marcado de esquema

| Ventaja | Detalle |
| :-- | :-- |
| **Más de 140 tipos de esquemas** | Cubre tipos de esquemas comunes como LocalBusiness, Product, Article/BlogPosting, FAQPage, Event, Organization y más. |
| **Vista de formulario (sin código)** | Los campos guiados facilitan la cumplimentación de los detalles del esquema sin necesidad de conocimientos técnicos. |
| **Vista JSON (Avanzada)** | Pegue o escriba JSON-LD directamente cuando necesite un control total. |
| **Validación integrada** | Resalta los problemas al guardar para que pueda corregir los problemas de esquema antes de publicar. |
| **Flujo de guardar y publicar con un solo clic** | El esquema se guarda en la configuración de la página y se activa cuando se publica la página. |
| **Múltiples esquemas por página** | Agregue y administre más de un tipo de esquema en la misma página (por ejemplo, LocalBusiness \+ FAQPage). |

## Cómo usar la IA para generar marcado de esquema

La generación de esquemas mediante inteligencia artificial permite crear automáticamente datos estructurados a partir del contenido de la página. Esto mejora la visibilidad en los motores de búsqueda y garantiza la precisión del esquema sin necesidad de configuración manual.

Antes de generar el marcado de esquema, es importante preparar correctamente la página. La IA se basa en el contenido existente para determinar los tipos y valores de esquema adecuados, por lo que las páginas incompletas pueden generar un esquema de salida inexacto o limitado.

### Antes de comenzar

Antes de generar el marcado del esquema:

- Asegúrese de que el contenido de su página esté completamente terminado.
- La IA analiza el contenido existente para generar un esquema preciso.
- El esquema se aplica por página y no se transfiere a otras páginas.

## Cómo generar manualmente marcadores de esquema

La configuración correcta empieza por abrir exactamente la página de Website o el paso de Funnel que quieres optimizar, y luego añadir el esquema que corresponda al contenido que los visitantes pueden ver. Como el esquema es específico de cada página, repetirás estos pasos en cada página o paso donde quieras datos estructurados.

<Steps>
  <Step title="Ve a Sites">
  </Step>
  <Step title="Haz clic en Funnels o Websites">
    Según a cuál quieras añadir el esquema.
  </Step>
  <Step title="Crea o edita">
    Crea un nuevo Funnel/Website, o edita uno existente.
  </Step>
  <Step title="Haz clic en Edit">
    Sobre la página de Website o el paso de Funnel específico que quieras actualizar.
  </Step>
  <Step title="Abre SEO & AI search optimization">
    En el panel izquierdo.
  </Step>
  <Step title="Haz clic en Schema Markup">
  </Step>
  <Step title="Añade el esquema">
    Haz clic en el botón **\+ New Schema** y selecciona la opción **Add Schema**.
  </Step>
  <Step title="Confirma en la ventana emergente">
    En el pop-up, haz clic en la opción **\+ Add Schema**.
  </Step>
  <Step title="Selecciona el tipo de esquema">
    Elige un tipo desde el desplegable (por ejemplo: Local Business, FAQ Page, Product, Article/Blog Posting).
  </Step>
  <Step title="Añade los detalles">
    Usa una de estas dos vías:

    - **Form View:** rellena los campos guiados.
    - **JSON View:** pega o escribe tu JSON-LD.
  </Step>
  <Step title="Completa la información">
    Añade la información necesaria según la categoría elegida.
  </Step>
  <Step title="Valida y guarda">
    Haz clic en **Validate & Save**.
  </Step>
  <Step title="Corrige si falla">
    Si la validación falla, corrige los campos resaltados o los problemas de formato del JSON.
  </Step>
  <Step title="Guarda y publica">
    **Save & Publish** la página de Website o el paso de Funnel para poner el esquema en vivo.
  </Step>
</Steps>

## Tipos de esquema compatibles para el método manual

El Generador de Marcado de Esquema admite una amplia variedad de tipos de esquema para que puedas hacer coincidir los datos estructurados con los objetivos de tu página. Usar el tipo correcto mejora la claridad para los motores de búsqueda y los sistemas de IA, y ayuda a que tu página califique para resultados enriquecidos donde corresponda.

Los tipos compatibles más comunes incluyen:

|  |  |
| :-- | :-- |
| Organization | Local Business |
| Website | Event |
| Breadcrumb List | Offer |
| Article / Blog Posting | Review |
| FAQ Page | Aggregate Rating |
| QA Page | Recipe |
| How To | ImageObject |
| Video Object | Service |
| Person | Course |
| Product |  |

<Note>
  **Nota:** Esto incluye los tipos hijos dentro de cada categoría (por ejemplo, los subtipos de LocalBusiness).
</Note>

## Notas importantes

- No se puede generar esquema para páginas vacías.
- Revisa siempre el esquema generado por IA antes de guardar.
- Cada página requiere su propia configuración de esquema.
- Actualizar el contenido de la página puede requerir volver a generar el esquema.
- El esquema solo se aplica después de publicar.

## Vistas de esquema: Vista de formulario frente a vista JSON

Elegir la vista de edición correcta te ayuda a trabajar más rápido y a reducir errores. Form View es ideal para la mayoría de usuarios, mientras que JSON View es mejor cuando necesitas pegar esquema de otra fuente o personalizar campos avanzados.

|  | Form View | JSON View |
| :-- | :-- | :-- |
| **Ideal para** | Configuración sin código | Usuarios avanzados y desarrolladores |
| **Cómo funciona** | Usa campos guiados para completar las propiedades obligatorias y recomendadas | Permite editar JSON-LD directamente o pegar un esquema existente |
| **Ventaja principal** | Ayuda a evitar errores de formato | Útil para añadir propiedades especializadas que no aparecen en Form View |

## Mejores prácticas para el éxito

| Práctica | Detalle |
| :-- | :-- |
| **La precisión es crítica** | Solo marca información que sea visible en la página. Nunca añadas reseñas falsas ni contenido oculto. |
| **Manténlo actualizado** | Actualiza el esquema cuando cambien los horarios comerciales, los precios o la información de contacto. |
| **Usa tipos específicos** | Elige “Dentist” en lugar del genérico “LocalBusiness” siempre que sea posible: cuanto más específico, mejor. |
| **Combina varios esquemas** | Tu página de inicio puede incluir a la vez esquema Organization y LocalBusiness para una cobertura completa. |
| **Añade esquema a todas las páginas clave** | Página de inicio, página de contacto, páginas de producto/servicio y entradas de blog se benefician todas del marcado adecuado. |

## Tipos de esquemas más útiles para negocios locales

| Tipo | Para qué sirve |
| :-- | :-- |
| **Local Business** | Esencial para cualquier negocio con ubicación física. Incluye nombre, dirección, teléfono, horarios y área de servicio. |
| **Product** | Para los artículos que vendes. Muestra precios, disponibilidad, valoraciones e imágenes directamente en los resultados de búsqueda. |
| **Service** | Para los servicios que ofreces. Muestra descripciones de servicio, precios y áreas de servicio. |
| **Review** | Testimonios de clientes que aparecen como valoraciones con estrellas en los resultados de búsqueda (deben ser reseñas reales). |
| **FAQ** | Preguntas y respuestas que se despliegan directamente en los resultados de búsqueda. |
| **Event** | Talleres, ventas, clases o cualquier evento programado. Muestra fechas y enlaces de registro. |

## Es bueno saberlo

- El esquema es específico de la página y no se transfiere automáticamente a otras páginas ni a pasos del embudo.
- El esquema puede aparecer en el editor o en la vista previa después de guardar, pero solo se activa una vez que la página se publica.
- El esquema no se genera automáticamente al crear una página nueva con IA: añádelo manualmente una vez que el contenido esté terminado.
- Mantén el esquema actualizado cuando cambien los detalles visibles (por ejemplo: horarios comerciales, precios, información de contacto).

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿En qué se diferencia la selección de esquema entre la configuración manual y los esquemas generados por IA?">
    En la configuración manual, los tipos de esquema disponibles se limitan a una lista predefinida, normalmente los más usados para SEO, AEO (Answer Engine Optimization) y GEO (Generative Engine Optimization).

    Con IA no existe esa limitación. La IA puede generar cualquier tipo de esquema válido basado en el contenido de la página.
  </Accordion>

  <Accordion title="¿Puede la IA generar tipos de esquema que no están en la lista manual?">
    Sí. La IA puede analizar el contenido de la página y crear marcado de esquema usando cualquier tipo válido, incluso si no está incluido en las opciones de selección manual.
  </Accordion>

  <Accordion title="¿Necesito conocimientos técnicos para usar el Generador de Marcado de Esquema?">
    No. Form View está diseñada para una configuración sin código. Los usuarios avanzados pueden usar JSON View para pegar o personalizar JSON-LD.
  </Accordion>

  <Accordion title="¿Dónde se publica el esquema en mi página?">
    El esquema se publica como JSON-LD en el `<head>` de la página cuando la página se publica.
  </Accordion>

  <Accordion title="¿Por qué veo el esquema en la vista previa pero no en la página en vivo?">
    Guardar almacena el esquema para la página, pero solo se pone en vivo después de que publiques la página o el paso del embudo.
  </Accordion>

  <Accordion title="¿Puedo añadir más de un tipo de esquema a una misma página?">
    Sí. Puedes agregar y administrar múltiples esquemas por página (por ejemplo, LocalBusiness \+ FAQPage).
  </Accordion>

  <Accordion title="¿Puedo pegar esquema de otra herramienta o sitio web?">
    Sí. Usa JSON View para pegar tu JSON-LD, y luego haz clic en **Validate & Save** para comprobar si hay problemas antes de publicar.
  </Accordion>

  <Accordion title="¿Qué comprueba “Validate & Save”?">
    La validación ayuda a identificar campos ausentes o incorrectos y problemas de formato, para que puedas corregirlos antes de publicar.
  </Accordion>

  <Accordion title="¿Mi esquema debe coincidir con lo que se ve en la página?">
    Sí. Añade únicamente datos estructurados que reflejen contenido real que los usuarios puedan ver, para evitar marcado engañoso.
  </Accordion>

  <Accordion title="¿Puedo generar esquema sin contenido en la página?">
    No. La página debe contener contenido para que la IA genere un esquema preciso.
  </Accordion>

  <Accordion title="¿Puedo editar el esquema generado?">
    Sí. Puedes modificar el esquema tanto en Form View como en JSON View antes de guardar.
  </Accordion>
</AccordionGroup>
