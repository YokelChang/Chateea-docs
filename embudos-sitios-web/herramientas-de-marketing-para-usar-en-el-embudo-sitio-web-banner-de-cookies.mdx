## Nota importante

<Warning>
  Es necesario eliminar las etiquetas `<noscript>` porque el banner de cookies de LeadConnector es una solución basada en JavaScript. Está diseñado para navegadores que no admiten JavaScript, y su inclusión podría instalar cookies involuntariamente sin el consentimiento del usuario.
</Warning>

### Integración de herramientas de marketing con el consentimiento de cookies

Al integrar herramientas de marketing con el banner de consentimiento de cookies, puedes comprobar a qué categorías de cookies han dado su consentimiento los usuarios. Sigue la guía de implementación proporcionada para las herramientas de marketing más populares.

<Note>
  **Nota de implementación:**

  El siguiente código debe reemplazar tus códigos de seguimiento de Meta Pixel, Google Tag Manager (GTM) o Google Analytics (GA). Insértalo en el código del encabezado de la página o en la configuración del código de seguimiento de la cabecera para embudos de conversión, sitios web o seminarios web. Esta plantilla garantiza una correcta integración con el banner de consentimiento de cookies.
</Note>

## Lectura de categorías de cookies

El siguiente código es opcional si desea leer el consentimiento o las categorías que el usuario ha aceptado para otro código personalizado o JavaScript de terceros.

```javascript
// Helper function to get consented categories
function getConsentedCategories() {
  const categoriesCookie = document.cookie
    .split('; ')
    .find(row => row.startsWith('cookie-categories='));

  if (categoriesCookie) {
    // Convert cookie value to array
    return categoriesCookie.split('=')[1].split(',');
  }
  return [];
}

// Helper function to check if category is allowed
function isCategoryAllowed(category) {
  const categories = getConsentedCategories();
  return categories.includes(category);
}

// Helper function to get cookie config
function getCookieConfig() {
  const cookieConfig = document.cookie
    .split('; ')
    .find(row => row.startsWith('cookie-config='));

  if (cookieConfig) {
    return cookieConfig.split('=')[1]; // Returns: all, essential, or custom
  }
  return undefined; // Return undefined if user hasn't made a choice yet
}
```

## Notas importantes

1. Las categorías de cookies se almacenan en la cookie `cookie-categories`.
2. Las categorías están separadas por comas (por ejemplo, "esenciales,publicidad,análisis").
3. Siempre verifique el consentimiento inicial al cargar sus herramientas de marketing.
4. Escuchar los eventos de cambio de consentimiento para actualizar la configuración de la herramienta.
5. Elimina cualquier etiqueta `<noscript>` ya que podría eludir las comprobaciones de consentimiento.
