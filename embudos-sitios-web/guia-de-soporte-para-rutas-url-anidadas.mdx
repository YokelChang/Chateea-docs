## Descripción general

La función **Rutas de URL Anidadas** te permite crear URL jerárquicas para tus embudos de conversión, sitios web y seminarios web utilizando barras diagonales ( `/` ) para representar la estructura del sitio. En lugar de que las barras diagonales se conviertan en guiones, ahora puedes definir rutas anidadas significativas que reflejen la organización de tu contenido y mejoren el SEO.

### Ejemplos de rutas anidadas

```text
/recursos/cursos/embudo-de-ventas
/webinars/2025/sesión-de-verano
/campañas/vacaciones/oferta-black-friday
/funnels/product-launch/step-1
```

## Validación de ruta y restricciones

### Senderos reservados

Ciertas rutas están reservadas para el funcionamiento del sistema y no se pueden utilizar. Intentar utilizarlas generará un mensaje de error.

### Rutas del sistema

| Ruta | Reservada para |
| :-- | :-- |
| `/b/` | La funcionalidad de blogs |
| `/c/` | Categorías |
| `/producto/` | Páginas de productos |
| `/colecciones/` | Las páginas de colecciones |
| `/post/` | Entradas de blog |
| `/categoría/` | Páginas de categorías |
| `/autor/` | Las páginas de autor |
| `/tag/` | Páginas de etiquetas |
| `/store/account` | La funcionalidad de la cuenta de la tienda |

<Warning>
  Si introduces una ruta reservada, el editor mostrará el mensaje **"This URL contains a reserved path that cannot be used"** y no te dejará guardar.
</Warning>

## Mejores prácticas

| Práctica | Detalle |
| :-- | :-- |
| **Evite las barras diagonales finales** | Utilice rutas limpias y canónicas sin una barra diagonal final (por ejemplo, `/ruta/subruta` en lugar de `/ruta/subruta/`). |
| **Elimine las barras dobles** | Asegúrese de que no haya barras duplicadas en sus rutas (por ejemplo, `/ruta/subruta`, no `/ruta//subruta`). |
| **No deje segmentos vacíos** | Evite dejar segmentos en blanco entre las barras (por ejemplo, use `/categoría/elemento`, no `/categoría//elemento`). |
| **Utilice rutas descriptivas y significativas** | Comunique claramente el contenido y su jerarquía con URL legibles e intuitivas (por ejemplo, `/blog/seo-tips` en lugar de `/b/123`). |
| **Organízate de forma lógica** | Estructura las rutas de forma que tengan sentido para los visitantes y reflejen la navegación o la jerarquía de contenido de tu sitio web. |
| **Optimización para SEO** | Las rutas bien estructuradas y ricas en palabras clave pueden mejorar el posicionamiento en los motores de búsqueda al indicar relaciones de contenido claras. |

## Conclusión

Las rutas URL anidadas ofrecen una gran flexibilidad para organizar el contenido y mejorar el SEO del sitio. Siguiendo estas directrices y evitando las rutas reservadas, se puede crear un sitio web jerárquico y bien estructurado, fácil de usar y optimizado para los motores de búsqueda.

<Tip>
  **Pruebe siempre a fondo sus rutas anidadas y asegúrese de que se ajusten a la arquitectura general de su sitio web y a sus objetivos de marketing.**
</Tip>
