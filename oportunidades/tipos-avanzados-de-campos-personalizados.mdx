Además de los campos de texto, número o desplegable de siempre, Chateea ofrece tipos de campo personalizado más avanzados para recoger la información con el formato exacto que necesitas: direcciones web con reglas de dominio, fechas y horas con restricciones, texto con formato, usuarios del equipo y opciones de selección con imágenes o íconos.

## Qué aportan estos campos

- **URL con control de dominios:** guardas enlaces en un campo específico y decides qué dominios se aceptan.
- **Fechas y horas más precisas:** eliges si el campo pide fecha y hora, solo fecha o solo hora, y limitas qué fechas se pueden elegir.
- **Texto con formato:** organizas información larga con títulos, listas, negritas y cursivas.
- **Usuarios del equipo:** asocias a una o varias personas del equipo con el registro.
- **Opciones más visuales:** añades imágenes a las casillas de verificación e imágenes o íconos a las opciones de selección única.

## Campo URL

Úsalo para guardar direcciones web en lugar de un campo de texto genérico: sitio web de la empresa, perfiles sociales, portafolios, enlaces a recursos o a proyectos.

Al configurarlo, eliges cómo se tratan los dominios:

| Opción | Resultado |
| --- | --- |
| **Permitir todos los dominios** | Se acepta cualquier URL. |
| **Permitir solo dominios específicos** | Solo se aceptan URL de los dominios que indiques. |
| **Bloquear dominios específicos** | Se acepta cualquier URL excepto las de los dominios bloqueados. |

## Campos de fecha y hora

Elige el formato según lo que necesites registrar:

- **Fecha y hora:** una fecha de calendario y una hora concreta.
- **Solo fecha:** una fecha sin hora.
- **Solo hora:** una hora sin fecha, por ejemplo, la hora preferida para contactar.

En los campos con fecha puedes limitar qué días se pueden seleccionar:

- **Solo fechas futuras:** impide elegir fechas pasadas.
- **Solo fechas pasadas:** impide elegir fechas futuras.
- **Rango de fechas específico:** limita la selección a un periodo definido.

Por ejemplo, una restricción a fechas futuras evita que alguien registre por error una fecha de renovación en el pasado.

## Campo de texto enriquecido

Pensado para información que necesita más estructura que un texto plano: notas detalladas, instrucciones, resúmenes. Admite negritas, cursivas, títulos, listas y otros formatos de texto. Si solo necesitas un valor corto sin formato, basta con un campo de texto estándar.

## Campo de usuarios

Permite asociar a una o varias personas de tu equipo con un registro, por ejemplo, todas las que colaboran en un mismo negocio. Puedes configurarlo para admitir un solo usuario o varios.

Los usuarios seleccionados reciben acceso de **seguidor** sobre el registro, así se mantienen al tanto de su actividad.

<Note>
Seleccionar a alguien en un campo de usuarios no lo convierte en propietario del registro. Para asignar la responsabilidad principal, usa el campo de propietario.
</Note>

## Imágenes en casillas de verificación

Cada opción de una casilla de verificación puede llevar una imagen junto al texto. Es útil cuando la imagen explica la diferencia entre opciones mejor que las palabras: productos, diseños, categorías visuales o preferencias de estilo. Recuerda que las casillas permiten elegir **varias** opciones.

## Imágenes e íconos en opciones de selección única

Las opciones de selección única (radio) pueden llevar una imagen o un ícono. A diferencia de las casillas, aquí solo se elige **una** opción, así que son ideales para escoger un diseño, un plan o una categoría.

## Crear un campo avanzado

<Steps>
  <Step title="Abre los campos personalizados">
    Ve a **Configuración → Campos personalizados**.
  </Step>
  <Step title="Elige el objeto">
    Selecciona el objeto donde quieres crear el campo, por ejemplo, Oportunidad o Contacto.
  </Step>
  <Step title="Crea el campo">
    Haz clic en **Crear campo** y elige el tipo adecuado.
  </Step>
  <Step title="Configura el nombre y los ajustes propios del tipo">
    - **URL:** define el control de dominios.
    - **Fecha y hora:** elige el formato y las restricciones de fecha.
    - **Texto enriquecido:** úsalo para contenido que necesita formato.
    - **Usuarios:** indica si admite uno o varios usuarios.
    - **Casilla de verificación:** añade imágenes a las opciones que lo necesiten.
    - **Selección única:** añade imágenes o íconos a las opciones.
  </Step>
  <Step title="Revisa y guarda">
    Revisa la configuración y la vista previa, y guarda el campo.
  </Step>
</Steps>

<Warning>
La disponibilidad de cada tipo de campo puede variar según el objeto o la parte de Chateea donde lo uses. Comprueba que el tipo está disponible para tu caso antes de construir un proceso a su alrededor.
</Warning>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Uso un campo URL o un campo de texto para las direcciones web?">
    Si el dato es siempre una dirección web, usa el campo URL: además puedes controlar qué dominios se aceptan.
  </Accordion>
  <Accordion title="¿Puedo pedir solo una hora sin fecha?">
    Sí, con el formato **Solo hora**.
  </Accordion>
  <Accordion title="¿Puedo impedir que se elijan fechas pasadas?">
    Sí, con la restricción **Solo fechas futuras**. También puedes limitar a fechas pasadas o a un rango concreto.
  </Accordion>
  <Accordion title="¿Casillas de verificación u opciones de selección única?">
    Usa casillas cuando se puedan elegir varias opciones y selección única cuando solo deba elegirse una. Las casillas admiten imágenes; la selección única admite imágenes o íconos.
  </Accordion>
</AccordionGroup>
