Un bot de IA se puede usar de dos formas distintas, y elegir mal complica la operación sin necesidad.

<CardGroup cols={2}>
  <Card title="Bot principal" icon="star">
    Atiende como primera línea en un canal. Responde a todo el que escriba, sin que nadie lo invoque.

    Es el modo por defecto y el que usa la mayoría de los negocios.
  </Card>

  <Card title="Bot secundario" icon="diagram-project">
    Se agrega dentro de un flujo de trabajo. Solo actúa cuando el flujo lo llama, en el punto exacto que tú definiste.

    Da mucho más control sobre cuándo interviene.
  </Card>
</CardGroup>

## Cuál te conviene

| Necesitas | Usa |
| --- | --- |
| Responder todo lo que entre por un canal | Principal |
| Atender fuera de horario | Principal |
| Calificar solo los leads de una campaña específica | Secundario |
| Intervenir en una etapa concreta del pipeline | Secundario |
| Distinto comportamiento según el origen del contacto | Secundario |
| Que actué después de que ocurra algo concreto | Secundario |

<Tip>
  Regla práctica: si la respuesta a "¿cuándo debe hablar este bot?" es **siempre**, es principal. Si es **cuando pase X**, es secundario.
</Tip>

## Combinarlos

Puedes tener ambos. Un bot principal atendiendo todo lo entrante, y bots secundarios especializados que se activan desde flujos para procesos concretos.

<Warning>
  Si un bot principal y uno secundario pueden activarse en la misma conversación, vas a tener respuestas cruzadas.

  Define condiciones que no se solapen, y usa [condiciones de parada](/bot-ia/condiciones-de-parada) para que uno se detenga cuando el otro toma el control.
</Warning>
