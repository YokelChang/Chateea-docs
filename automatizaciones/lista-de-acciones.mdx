Las acciones son los pasos que ejecuta un flujo de trabajo después del disparador, en el orden exacto en que los colocas. Esta página reúne las acciones disponibles en Chateea, agrupadas por categoría, con qué hace cada una y para qué te sirve.

## Cómo agregar una acción

En el constructor de flujos, haz clic en el botón **+** de la línea del flujo. Se abre el menú de acciones, donde puedes buscar por nombre o navegar por categorías. Después configura la acción y guárdala.

## Contacto

| Acción | Qué hace | Para qué te sirve |
| --- | --- | --- |
| Crear contacto | Agrega un contacto nuevo. | Registrar clientes potenciales automáticamente. |
| Buscar contacto | Localiza un contacto existente con los datos que indiques. | Encontrar un registro para actualizarlo o usar sus datos. |
| Actualizar campo del contacto | Cambia un campo concreto del contacto. | Mantener la ficha al día sin trabajo manual. |
| Agregar etiqueta | Añade una etiqueta al contacto. | Segmentar y organizar tu base de contactos. |
| Quitar etiqueta | Elimina una etiqueta del contacto. | Mantener limpia la segmentación. |
| Asignar a usuario | Asigna el contacto a un usuario del equipo. | Repartir contactos y responsabilidades. |
| Quitar usuario asignado | Elimina la asignación actual. | Reasignar o liberar contactos. |
| Editar conversación | Marca la conversación como leída o no leída, o la archiva o desarchiva. | Mantener ordenada la bandeja de Conversaciones. |
| Activar o desactivar No molestar | Cambia la preferencia de No molestar del contacto. | Respetar las preferencias de comunicación. |
| Agregar nota | Añade una nota a la ficha. | Dejar registro de lo que pasó con el contacto. |
| Agregar tarea | Crea una tarea vinculada al contacto. Si el flujo corre sin contacto, crea una tarea sin contacto; combínala con un webhook entrante para crear tareas internas. | Organizar seguimientos y pendientes. |
| Copiar contacto | Duplica el contacto en otra cuenta de Chateea a la que tengas acceso. | Compartir clientes entre sucursales o marcas. |
| Eliminar contacto | Borra el contacto. | Mantener la base de contactos limpia. |
| Modificar puntuación de interacción | Sube o baja la puntuación de interacción del contacto. | Medir qué tan comprometido está cada contacto. |
| Agregar o quitar seguidores | Añade o quita seguidores de la ficha del contacto. | Dar visibilidad del contacto a otras personas del equipo. |

## Comunicación

| Acción | Qué hace | Para qué te sirve |
| --- | --- | --- |
| Enviar correo | Envía un correo al contacto. | Seguimientos, novedades y avisos personalizados. |
| Enviar SMS | Envía un SMS al contacto. | Recordatorios y avisos rápidos. |
| Enviar mensaje de Slack | Envía un mensaje a Slack si tienes la integración. | Avisar a tu equipo en su canal de trabajo. |
| Llamar | Hace una llamada automática que conecta a tu equipo con el contacto. | Marcación automática y contacto rápido con clientes potenciales. |
| Messenger | Envía un mensaje de Facebook Messenger. | Atender a quienes te escriben por Facebook. |
| Mensaje directo de Instagram | Envía un mensaje directo de Instagram. | Conversar con clientes por Instagram. |
| Acción manual | Crea una tarea para que un usuario haga algo a mano con el contacto (por ejemplo, llamar o escribir). | Combinar automatización con el toque humano. |
| Mensajes de Perfil de Empresa de Google | Responde mensajes de tu Perfil de Empresa de Google. | Atender consultas de clientes locales. |
| Enviar notificación interna | Avisa a usuarios del equipo o al contacto. | Mantener informado al equipo de lo que ocurre. |
| Enviar solicitud de reseña | Envía una solicitud de reseña. | Conseguir más reseñas y cuidar tu reputación. |
| IA conversacional | Pone a la IA a gestionar la conversación con el contacto. | Responder más rápido en varios canales. |
| Messenger interactivo de Facebook | Envía un mensaje directo, con botones, a quien comentó una publicación de Facebook. | Convertir comentarios en conversaciones. |
| Instagram interactivo | Lo mismo para comentarios en Instagram. | Convertir comentarios en conversaciones. |
| Responder en comentarios | Responde en público los comentarios de Facebook o Instagram. | Aumentar la interacción con tus seguidores. |
| WhatsApp | Envía mensajes de WhatsApp. | Comunicarte por el canal preferido de tus clientes, respetando las reglas de WhatsApp. |
| Enviar mensaje de chat en vivo | Responde mensajes del chat de tu sitio web. | Atención en tiempo real. |

## Herramientas internas

| Acción | Qué hace | Para qué te sirve |
| --- | --- | --- |
| Si/Si no | Crea ramas según condiciones. | Dar a cada contacto el camino que le corresponde. |
| Espera | Pausa el flujo durante un tiempo o hasta un momento. | Programar mensajes y acciones más adelante. |
| Evento de objetivo | Lleva al contacto a un punto posterior del flujo cuando cumple una meta. | Saltarse pasos innecesarios. |
| División | Hace una prueba dividida dentro del flujo. | Comparar mensajes o caminos y quedarte con el mejor. |
| Actualizar valor personalizado | Cambia un valor personalizado de la cuenta. | Mantener datos dinámicos al día. |
| Ir a | Dirige al contacto hacia otro flujo. | Gestionar recorridos complejos sin duplicar pasos. |
| Quitar del flujo | Saca al contacto de un flujo. | Evitar mensajes que ya no aplican. |
| Funciones de lista | Buscan, filtran, transforman o calculan valores de listas de datos. | Trabajar con colecciones de datos. |
| Modo goteo | Hace avanzar a los contactos por lotes. | No saturar tus canales y cuidar la entregabilidad. |
| Formateador de texto | Da formato a un texto. | Limpiar y transformar datos. |
| Código personalizado | Ejecuta código JavaScript propio. | Procesos complejos que ninguna otra acción cubre. |

| Recoger respuesta en la llamada | Pide a quien llama que marque una opción. | Crear las ramas del menú. |
| Reproducir mensaje | Reproduce un mensaje durante la llamada. | Dar información o instrucciones. |
| Conectar llamada | Transfiere la llamada a un usuario o número. | Enviar cada llamada a la persona correcta. |
| Finalizar llamada | Cuelga la llamada. | Terminar la llamada tras un mensaje o acción. |
