El editor de texto que usas para redactar correos y plantillas tiene una interfaz renovada. En esta guía te explicamos cada herramienta para que saques el máximo provecho.

## Valores personalizados

Pulsa el icono **Valores personalizados** (Custom Values) para insertar datos dinámicos en tu plantilla, como el nombre del contacto o la fecha de una cita.

El menú incluye un buscador y los grupos **Contacto**, **Usuario**, **Cita**, **Calendario**, **Mensaje**, **Cuenta**, **Ahora mismo**, **Atribución** y **Valores personalizados**.

## Enlaces de activación

Pulsa **Enlaces de activación** (Trigger Links) y elige en el desplegable el enlace que quieres agregar a la plantilla. Estos enlaces te permiten saber quién hizo clic y disparar automatizaciones.

## Barra de formato

| Fila | Funciones disponibles |
| --- | --- |
| **Primera fila** | Deshacer, rehacer, negrita, cursiva, subrayado y tipo de fuente |
| **Segunda fila** | Tamaño de fuente, formato de párrafo, altura de línea, color del texto, color de fondo, lista con viñetas, lista numerada y alineación del texto |

La primera fila cubre el énfasis del texto y la segunda, la composición del párrafo (tamaño, interlineado, color y listas).

## Más opciones

Pulsa el icono de **más opciones** (tres puntos) para acceder a:

- Tachado
- Superíndice
- Subíndice
- Código
- Bloque de código
- Cita en bloque
- Formatear la selección
- Formatear todo el documento

## Agregar enlace

Pulsa el icono **Agregar enlace** (Add Link). En la ventana que se abre, pega la URL o elige un enlace de activación con el icono de la derecha. Luego indica cómo se abre y pulsa **Guardar**.

| Campo | Qué define |
| --- | --- |
| **URL** (obligatorio) | La dirección de destino, escrita a mano o insertada desde los enlaces de activación |
| **Acción** (obligatorio) | Si el enlace se abre en la misma página o en una ventana nueva |

## Agregar imagen

Pulsa el icono **Imagen** (Add Image). En la ventana que se abre puedes configurar:

| Campo | Qué define |
| --- | --- |
| **URL de la imagen** (obligatorio) | La dirección de tu imagen. También puedes subirla con el botón **Subir** |
| **Ancho y alto** | El tamaño de la imagen en píxeles |
| **Texto alternativo** (obligatorio) | Una descripción breve de la imagen, útil para accesibilidad y cuando la imagen no carga |
| **Enlace de la imagen** (Image Action Link) | La dirección que se abre cuando alguien hace clic en la imagen |
| **Abrir enlace en** (Open link in) | Si el enlace se abre en la misma ventana o en una nueva. Solo se activa si completaste el enlace de la imagen |

Si no rellenas el enlace de la imagen, el campo **Abrir enlace en** queda bloqueado, porque no hay destino que abrir.

## Código fuente

Pulsa el icono **Código fuente** (Source Code) para ver y editar el HTML de la plantilla en una ventana aparte. Cuando termines, pulsa **Guardar**.

<Tip>
  El editor de código fuente es la forma más rápida de ajustar detalles finos de maquetación (interlineado, listas, citas) que la barra de herramientas no permite afinar.
</Tip>
