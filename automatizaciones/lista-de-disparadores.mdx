Un disparador es el evento que pone en marcha un flujo de trabajo: se crea un contacto, alguien reserva una cita, llega un pago. Esta página reúne todos los disparadores disponibles en Chateea, agrupados por categoría, con una descripción corta de cuándo se activa cada uno.

## Cómo encontrar un disparador

En el constructor de flujos, haz clic en **Agregar disparador**. Se abre el menú de disparadores, donde puedes buscar por nombre o navegar por categorías. Después de elegirlo, configura sus filtros para que solo se active en los casos que te interesan.

Recuerda: el **disparador** inicia el flujo y las **acciones** son los pasos que se ejecutan después, en el orden en que los colocas.

## Contacto

| Disparador | Se activa cuando |
| --- | --- |
| Recordatorio de cumpleaños | Llega el cumpleaños del contacto, o los días antes o después que indiques. |
| Contacto modificado | Los campos del contacto que elijas cambian a los valores que definas. |
| Contacto creado | Se agrega un contacto nuevo al CRM. |
| No molestar del contacto | Se activa o desactiva la preferencia de No molestar de un contacto. |
| Etiqueta del contacto | Se agrega o se quita una etiqueta concreta. |
| Recordatorio de fecha personalizada | Se acerca, llega o pasa una fecha de un campo. Los campos disponibles dependen del tipo de flujo (contacto, fechas de oportunidad en flujos de contacto, objeto personalizado o empresa). |
| Nota agregada | Se añade una nota nueva al contacto. |
| Nota modificada | Se edita una nota existente. |
| Tarea agregada | Se crea una tarea para el contacto. |
| Recordatorio de tarea | Llega la hora del recordatorio de una tarea. |
| Tarea completada | Una tarea del contacto se marca como completada. |
| Puntuación de interacción del contacto | La puntuación de interacción cumple la regla que definas. |

## Eventos

| Disparador | Se activa cuando |
| --- | --- |
| Webhook entrante | Llegan datos a la URL de webhook del flujo. |
| Programador | Llega la fecha u hora programada, sin necesidad de un contacto. |
| Detalles de llamada | Un registro de llamada coincide con los detalles o resultados elegidos. |
| Eventos de correo | Un correo se entrega, se abre, recibe un clic, rebota, se marca como spam o el contacto se da de baja. |
| Cliente respondió | El contacto responde por cualquier canal conectado. |
| Disparador de IA conversacional | Ocurre un evento configurado de la IA conversacional. |
| Disparador personalizado | Ocurre un evento personalizado que definas para casos especiales. |
| Formulario enviado | Se envía un formulario de Chateea concreto. |
| Encuesta enviada | Se envía una encuesta concreta. |
| Clic en enlace de disparo | El contacto hace clic en un enlace de disparo definido. |
| Formulario de anuncios de Facebook enviado | Llega un registro de un formulario de anuncios para clientes potenciales de Facebook. |
| Formulario de TikTok enviado | Se envía un formulario de clientes potenciales de TikTok. |
| Seguimiento de video | Quien ve un video alcanza el porcentaje de reproducción que elijas. |
| Validación de número | Se obtiene el resultado de la validación del número de teléfono. |
| Error de mensajería SMS | Un SMS saliente devuelve un error concreto. |
| Formulario de LinkedIn enviado | Llega un registro de un formulario de generación de clientes potenciales de LinkedIn. |
| Visita a página de embudo o sitio web | El contacto visita una página, URL o UTM concreta. |
| Cuestionario enviado | Se envía un cuestionario concreto. |
| Nueva reseña recibida | Llega una reseña nueva en Reputación. |
| Prospecto generado | Se crea un registro de prospecto nuevo. |
| Anuncios Click to WhatsApp | Empieza una conversación de WhatsApp desde un anuncio Click to WhatsApp. |
| Evento de seguimiento externo | Se registra un evento de seguimiento con nombre, desde el navegador o desde un servidor. |

## Citas

| Disparador | Se activa cuando |
| --- | --- |
| Estado de la cita | Cambia el estado de una cita: reservada, reprogramada, cancelada, no asistió, etc. |
| Cliente reservó una cita | Un cliente reserva una cita. |
| Reserva de servicio | Se hace una reserva desde los calendarios de servicios. |
| Reserva de alquiler | Se reserva un alquiler. |

## Oportunidades

| Disparador | Se activa cuando |
| --- | --- |
| Cambio de estado de la oportunidad | Cambia el estado de una oportunidad (por ejemplo, de Abierta a Ganada o Perdida). |
| Oportunidad creada | Se crea una oportunidad nueva. |
| Oportunidad modificada | Cambian los campos elegidos de una oportunidad. |
| Cambio de etapa del pipeline | Una oportunidad pasa a otra etapa del pipeline. |
| Oportunidades estancadas | Las oportunidades cumplen tu regla de inactividad. |

## Afiliados

| Disparador | Se activa cuando |
| --- | --- |
| Afiliado creado | Se crea una cuenta de afiliado nueva. |
| Nuevas ventas de afiliado | Se atribuye una venta a un afiliado. Puedes filtrar por afiliado, campaña, estado del método de pago y estado del formulario fiscal. |
| Afiliado inscrito en campaña | Se agrega un afiliado a una campaña. |
| Cliente potencial creado | Se crea un cliente potencial atribuido a un afiliado. |

| Producto iniciado | Un alumno empieza un producto o curso. |

| Pedido enviado | Se completa un pedido en el pago. |
| Documentos y contratos | Cambia el estado de un documento: enviado, firmado o rechazado. |
| Presupuestos | Un presupuesto se envía, se acepta o se rechaza. |

| Cupón aplicado | Se aplica un código de cupón a una compra. |
| Límite de canjes del cupón alcanzado | Un cupón llega a su límite de canjes. |
| Cupón vencido | Vence un código de cupón. |
| Cupón canjeado | Se canjea un código de cupón. |
